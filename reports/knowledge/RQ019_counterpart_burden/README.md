# RQ019：异常 IPV 的代价由谁承担（知识层）

状态：**已接受主张，见本目录 `decision.md`（PI 裁定 2026-08-05）**

执行层：`reports/studies/RQ019_counterpart_burden/RQ019_1_counterpart_burden_20260805T014215Z_7b9f47b/`

## 问题

最终目标是**在线验证**：判断一辆自动驾驶车表现出的社会交互倾向像不像人。判定由两道串联
弃权机制构成——**机制一**判断某一帧的 IPV（Interaction Preference Value，表示交互倾向的
标量）是否携带七个候选间的判别信息；**机制二**用人类参照分布判断当前情境是否有足够人类
样本可比。

RQ018 发现 IPV 低于该情境人类参照下界（**比人类更激进**）时，自车侧安全裕度分布整体压缩，
但极端危险不增加。**RQ019 问：这个压缩的代价由谁承担。**

机制上这个问题是自洽的：IPV 的代价函数 `util = cos(ipv) × 自身代价 + sin(ipv) × 交互代价`
里，**`sin(ipv)` 正是对方代价的权重**，所以「向负偏离 ⇒ 对手方承担更多代价」是该量定义
本身的预测，不是外部借来的代理。

## 结论

**对手方承担了约两倍的常规运动调整，但双方都没有更多的紧急情形。**

非 scripted 主组、固定 3 秒窗口、α=90（下侧 1,821 帧 / 区间内 7,572 帧，173 个 case）：
锚点降速中位 **2.893 对 1.243 km/h（2.33×**，case bootstrap 95% CI [1.0127, 2.6155]）；
速度极差 **4.786 对 2.758 km/h（1.74×**，CI [1.2275, 2.7073]）。
强制动帧反而更少：`acceleration < −3 m/s²` 占比 2.832%(1,521/53,714) 对 7.020%(15,769/224,624)，
差 −0.0419，CI [−0.0627, −0.0219]，case 等权 p=0.0045。

**转向类不成立**：最大偏航角速度 CI [−0.4722, 7.9538] 跨 0。

## 方法学要点（后续复用）

1. **必须用原始竞赛日志。** 派生表的对手车速度是位置差分算的，`|a|>10 m/s²` 占 19.8%；
   原始日志直接记录 `speed`/`acceleration`/`courseAngle`，`|a|>10` 仅 0.0158%，
   下界恰为 −7.5 m/s²（仿真器制动上限）。
2. **单位陷阱**：原始日志 `speed` 是 km/h，派生表是 m/s。
3. **对齐配方**（三条硬断言全过）：`session_id` → 会话目录；`counterpart_key_agent` → 原始 `id`；
   `timestamp_ms` → 最近 `globalTimeStamp`（95 分位 48 ms）；去 per-case 恒定平移后位置残差
   中位 0.0992 m。
4. **组间中位数差必须做 case 层推断**。执行方只对制动占比做了，监督方补做速度与转向后
   才把结论上调；这一步不做会低估结论。

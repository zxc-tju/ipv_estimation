## 关键背景：这个门到底在防什么

**下溢是连乘域的数值 bug，log 域已经消除了它。所以弃权门不是用来检测下溢的。**

弃权门要处理的是**实质性不可辨识**：MSE 曲面是真的平（⇒ 无实质交互 ⇒ 合理地无判别信息），
还是有峰（⇒ 有判别信息）。PI 已接受的科学前提是：IPV 的可辨识性本来就依赖交互的存在性，
无实质交互的帧没有判别信息是**正常且合理**的。门的目的**不是**把失败率降到零，
而是**把「无判别信息」与「有判别信息且估计值为 0」分开记账**。

### D1 的操作定义（leader 已核验，直接用）

D1 = 连乘域全下溢回退行，判据 `legacy_fallback_triggered == True`。
在本样本中 n = 603，且这 603 行**同时**满足（已核验，全部无例外）：
`legacy_prod_sum == 0.0`、`ipv_legacy == 0.0`、
`ipv_error_legacy == 0.6220355269907728`（即 `1-1/sqrt(7)`）、`k_eff_legacy == 7.0`。
这就是"算不出来"与"完全自利"不可区分的那个病理签名。

⚠ **重要，别被它绊住**：本样本的 D1 率是 **26.22%**（waymo 47.91%、nuplan 4.52%），
与全语料审计报的 43.17%（waymo 58.93%、nuplan 1.10%）**不一致**。
这是**预期的**——2,300 锚点是刻意构造的分层样本（两个 source 各 1,150），
不是语料的随机抽样。**不要试图去凑 43.17%，不要认为哪一边错了。**
在报告里明确写一句：本轮所有比例均基于 2,300 锚点样本，样本 D1 率与全语料 D1 率因抽样设计而不同。

## 任务

### 任务 0（先做，这是本轮最有价值的单个数字）：救回率

切到 log 域之后，原本被判为 D1 的那 603 行里，有多少变成了**具有判别信息**的？

- 判据就用门本身（`k_eff_log <= tau`），所以数值上依赖 tau。
  为避免循环论证：**既报"在最终选定的 tau 下的救回率"，也报"救回率随 tau 的完整曲线"**。
- **分 source 报**（waymo / nuplan 必须分开）。
- 一并报 D1 行与非 D1 行的 `k_eff_log` 分布对比（min/p25/p50/p75/max）。

⚠ leader 已做过快速预览，你会看到一个**反直觉的方向**：D1 行的 `k_eff_log` 中位数约 1.44，
而非 D1 行约 6.99 —— 即 D1 行在 log 域反而是**判别力最强**的那批。
这在机制上是自洽的（连乘域下溢恰恰发生在似然很尖锐、各候选密度乘积极小的时候）。
**请独立复算确认这个方向，并在报告里解释这个机制。**
如果你的复算与此不符，以你的复算为准，但要明确写出分歧。

### 任务 1：门的定义

1. **必须建立在 log 域量上。** 任何建立在 `legacy_var` / `legacy_prod_sum` /
   `legacy_fallback_triggered` 之上的门都继承了它试图检测的病理，直接排除。
2. **首选统计量：`k_eff_log`**（CSV 里已有此列，不用自己重算；但请用 `w_log[7]` 抽查
   若干行验证 `q_eff = 1/((1-e)^2*K)`、`k_eff = q_eff*K` 的一致性，报告抽查结果）。
   范围严格 `[1,7]`：`k_eff=1` 质量全在一个候选（判别力最强），`k_eff=7` 均匀（无判别力）。
   门的形式即 `k_eff_log <= tau`。
3. **单一连续统计量优于清单式规则。** 如果你认为必须加第二个条件（例如 `n_obs` 下限），
   必须给出它**不能被 `k_eff_log` 吸收**的证据（例如：在固定 `k_eff_log` 分层内，
   该条件仍显著改变跨环境 `|Δipv_log|`）。**没有这种证据就不要加条件。**
   报告里要正面回答"为什么不需要第二个条件"。
4. **tau 不得靠肉眼选。** 用下面的验收测试反解：**取能通过验收判据的最宽松 tau**
   （即在满足判据的前提下让通过率最大），并给出 tau 对通过率、以及 tau 对
   通过者 p99 `|Δipv_log|` 的**双敏感性曲线**（建议 tau 从 1.0 到 7.0 扫描，步长 0.05 或更细）。

**门用哪个环境的 `k_eff_log`？** 主分析用 **MAC** 的 `k_eff_log`（本地即生产环境）。
另外报一个稳健性数字：在选定 tau 下，有多少锚点的门决策在两个环境间**翻转**
（Mac 通过但 HPC 不通过，或反之），以及翻转率。这一项只要一两个数字，不要展开成子研究。

### 任务 2：验收测试（决定性）

把跨环境 `|Δipv_log| = |ipv_log_mac - ipv_log_hpc|` 的分布**限制在通过门的锚点上**重算。

- 报**通过者**与**未通过者**各自的 p50 / p90 / p99 / max，
  **并按 source 分列（waymo / nuplan 必须分开，不得只报合并值）**
- **通过判据（PI 设定，不得放宽）：通过者的 p99 `|Δipv_log|` 必须 <
  一个网格间距 `pi/8 = 0.3926991`。**
  理由：跨环境差异超过一个网格步长意味着 argmin 本身在跳，此时报出来的数值没有意义。
- 判据要**同时**在合并样本和**每个 source 内部**检查；报告里明确写「通过 / 不通过」。
- ⚠ **若最宽松的 tau 都过不了这条判据 ⇒ `k_eff_log` 门无效，如实写下来并说明原因，
  不要为了让它通过而修改判据、不要换一个更宽松的判据、不要只报合并值掩盖 source 内失败。**
  这是一个可以否决自身设计的测试，这正是它的价值。

### 任务 3：通过率

合并通过率 + 分 source 通过率（在选定 tau 下）。

⚠ **预期 waymo 与 nuplan 的通过率差距很大。若两者差不多，反而说明门有问题，必须解释。**

### 任务 4：选择偏倚刻画

带门意味着个体层面样本量会掉，且掉得不随机。把**通过者 vs 未通过者**的协变量分布摊开对比，
至少含：`source`、`n_obs`（**给分布，不是只给均值**——至少 min/p25/p50/p75/max，
最好给个分箱计数表）、`signature`、`n_band`。
若样本中可得"是否存在交互机会"的指示，一并纳入；如果不可得，明确写"本样本中不可得"，
不要编造代理变量。

### 任务 5：区间宽度的下界校准

论文要求个体量强制带不确定性区间。用现成的跨环境差异给区间做一次**外部校准**：

- **在通过者上，你构造的区间半宽必须 >= 观测到的通过者 p99 `|Δipv_log|`。**
- 区间构造方式你自己定，但**必须说明选了哪种、为什么**。两个自然候选：
  (a) `w_log[7]` 是网格上的正规化后验，可直接取离散后验的可信区间（如 95%）；
  (b) 对帧做 bootstrap。
- ⚠ **若你构造的区间比 p99 窄，那个区间就是在说谎，须如实指出并说明差多少（给倍数或绝对差）。**
  特别注意：后验极尖锐（`k_eff_log→1`）时离散可信区间会塌到单个网格点，半宽可能是 0 或 `pi/16`。
  这种情况很可能**导致校准失败**，这是一个真实且必须报告的发现，不要回避。
  若发生，请一并报告"要满足校准需要的最小半宽下界"是多少。

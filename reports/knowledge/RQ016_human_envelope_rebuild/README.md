## 问题

在线验证要判断一辆自动驾驶车表现出的社会交互倾向像不像人。判定由两道串联的弃权机制
构成：机制一判断某一帧的 IPV（Interaction Preference Value，表示交互倾向的标量）数值
能否估出，估不出则直接弃权、不进机制二；机制二判断当前场景收集到的人类样本是否足以
判断该车是否偏离。RQ015 完成并冻结了机制一。

**RQ016 的问题是**：机制二依赖的人类参照分布（envelope，即 RQ009 已接受的
context-conditioned split-conformal 区间）建在一个含伪零的样本上。旧估计器在数值下溢时
退回七候选等权，候选网格对称，必然写出 IPV 恰为 0，使「没估出来」与「恰为中性」不可区分。
RQ015-L1 已证实：RQ009 精确零点原子里 48.0223%（92,333/192,271）不是中性点值，
而是弃权被写成了 0。

于是要问：只用过门样本重建 envelope 之后，机制二的覆盖行为、区间宽度、以及两道门
合起来的整体弃权率会变成什么样。

## 本轮的描述性发现（尚未作为手稿主张接受）

**F1 — 旧的人类 envelope 偏窄，且偏窄可归因于伪零。**
在 `development + guard` 域上同法跑两臂，唯一变量是样本口径。90% 名义层下，
只保留过门样本后 coverage 由 0.898832（758,857/844,270）变为 0.902689（545,159/603,928），
平均区间宽度由 1.016189 变为 1.300967，即 **+28.02%**。
覆盖基本不变而区间宽近三成。

机制证据（监督方独立测得，独立于执行方的 conformal 实现）：目标 `target_ipv_future` 的
四分位距由 A 臂 0.0493 变为 B 臂 0.2017，约 4.09 倍；恰为 0 的行由
192,221/888,892 = 21.6248% 降为 99,908/635,618 = 15.7182%。
另以完全不训练模型的边际分位数宽度复核，B/A 比值在 80/90/95 三层为
1.3763 / 1.1896 / 1.0130，与条件宽度比同向同量级。

**实际含义**：旧 envelope 会比人类数据本身所支持的更频繁地把一辆车判为「不像人」。

**F2 — 两道门串联后的整体可用率。**
合并弃权率 32.0583%（284,964/888,892），其中机制一贡献 28.4932%（253,274/888,892）、
机制二贡献 3.5651%（31,690/888,892）。即在该域上约 68% 的帧可进入在线判定，
且弃权几乎全部来自机制一。

## 效度边界

1. **不构成对 RQ009 的复现或证伪。** RQ009 的 test 域包含 RQ007 held_out，本轮受红线
   约束只能在 `development + guard` 上工作。两臂对比是本轮全部结论来源；
   RQ009 已发表数仅作外部参照。
2. **零点聚集只被减半，没有消除。** `|y| < 1e-6` 的行占比 A 臂 42.39%（分母 888,892）、
   B 臂 29.63%（分母 635,618）。重建后的 envelope 仍建在高度零点聚集的目标上。
3. 支持门用 12 项距离特征而非 RQ009 原门的 15 项，排除了 3 个由旧估计器算出的
   `counterpart_ipv_*` 列。理由与判据见执行报告附录 E。
4. 描述性结果，不得写成因果主张。
5. 全文禁用 `estimability` 与「测出/未测出 IPV」表述。可辩护说法是：
   权重近均匀 ⇒ 该 IPV 数值不携带候选间的判别信息。

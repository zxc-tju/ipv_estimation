# RQ020-v3 复审 A：从任务书出发

## 定位与总评

RQ020-v3 要解决的是：在 WOD-E2E 的三候选场景内，检验候选轨迹相对纯人-人 IPV 参照的偏离是否与人类评分相关。项目整体已有 RQ010B 的有界零结果、RQ014 的同数据规格恢复筛查，以及 RQ016C 的纯人-人参照模型；本次审查的是能否把这三块拼成一次有确认性含义的检验。

**总判定：`NO_GO`。** 阶段一的数值配置可以作为一个固定计算配方复用，四格也可以作为盲态描述性诊断；但 v3 不能把同一 rated479 上的结果解释为新的确认性检验。核心原因是 R04N / CH-W25 / H20 / terminal row 这组配方来自同一批评分上的 320 格、960 行筛查。更换参照模型没有更换结果数据，也没有消除配置选择对该批评分的依赖。

另有一个先于统计推断的硬问题：任务书没有冻结完整的 WOD→RQ016C 测量合同。RQ016C 的目标量与 RQ020 阶段一的 IPV 不是同一个已证明等价的量，且区间层、逐行支持判定如何归约到候选和场景也未写死。因此阶段二目前连唯一可解释的 NEX/NMD 数值都没有定义完。

本审查没有读取任何单场景评分值，没有访问任务书列出的禁读目录，没有运行估计器或作业，也没有执行 Git 写操作。

## 原始依据核验

1. **RQ014 配置与枚举核实。** `reports/plans/RQ014_recovery_lane_v3.json` 的 `rating_blind_feature_bank` 确实冻结了 exact solver、σ=0.1、7 点网格、R04N=4 Hz、CH-W25=`[tau-2.5,tau]`、H20=`tau=1.0..2.0`、完整窗口、禁止缩窗和跨窗状态复用、terminal estimator row。枚举为 16 个 feature family × 2 个 horizon × 10 个 readout = **320 个 predictor cell**；每格有 RWS/PSP/PPR 三种关联，合计 **960 行**。
2. **RQ014 结果核实。** `reports/studies/RQ014_wod_e2e_rating_recovery/03_results/RQ014_final_report_20260725.html` 记录唯一兼容行为 `RR3-R04N-CH-W25-H20-NMD_MEAN-RWS`，`r=-0.384`、`n=42` 个场景、126 个候选；primary NEX 通过数为 0。任务书第 46 行把实际后缀 `RWS` 写成了 `n`。`reports/knowledge/RQ014_wod_e2e_rating_recovery/README.md` 还确认：`selected_recovery_recipe.json` 未落位，clean replay 未通过，状态只能是 `PENDING_REPLAY`，无已接受经验主张。
3. **选择效应核实。** RQ014 合同把目标明确写成 `KNOWN_RESULT_SPECIFICATION_RECOVERY`，使用全 rated479、无 split，并明写 independent replication 未提供、p 值不控制 recovery。独立复审 `reports/knowledge/RQ014_wod_e2e_rating_recovery/reviews/codex_review.md` 第 90–102 行明确指出：fold/LOO/LOCO 是同一 selected support 上的内部删样，不是独立验证；若要在同一数据上校准偶然通过率，置换时必须重跑完整选择流程。
4. **RQ010B 数字核实。** `reports/studies/RQ010_wod_e2e_tracking_feasibility/RQ010B_1_tracking_preference_20260625T201647+0800_695fa83f/02_process/05_reframed_preference_results/phase3_effect_summary.csv` 中 `[−0.188,0.155]` 是 Scheme 1 的 **raw signed IPV Spearman** 区间，不是全部主检验共享的区间。两个主执行口径的场景数为 75 和 98，IPV strength=0；物理特征强度范围约 0.16–0.26，max-statistic permutation p=1。任务书的“≤15%”也不是精确值：冻结 prereg addendum 写的是 **35/228=15.35%**。RQ010B 仍然是有界且功效受限的零结果，但不能用一个 raw-IPV 区间代表所有端点。
5. **RQ016C 参照核实。** `key_numbers.json` 给出的纯人-人池确为 **2,442,625** 行，分为 train 974,984、calibration 481,088、guard_tune 499,893、test 486,660；90% 层在支持门后 coverage 为 **414,837/461,937=0.898038**，test 弃权 **24,723/486,660=5.0801%**。OnSite dry-run 是 **21,936/67,861=32.3249%** 通过。pkl 实体存在，大小 171,911,135 B，SHA-256 为 `bc25302b4a7a307e3c73b3429b880e3cfda59074fc80850a732a93a67ef75de2`。这些证据只证明 InterHub 测试域的覆盖与 OnSite 接口可运行；知识层明确写着没有 WOD/OnSite 同源迁移证据。
6. **RQ016C 目标语义核实。** `feature_contract.json` 的 target 是 `target_ipv_future`。RQ009 的 `feature_dictionary.csv` 第 15–18、57 行把它定义为：跳过一行 guard 后，在 `t*+6` 取 ego 的 hw=4 future IPV；相应构建说明又规定目标只由五行 `W_y` 计算。RQ020 阶段一则要取 R04N/CH-W25 的 2.5 s 因果窗 terminal row。列名兼容不等于目标量兼容，现有材料没有给出二者等价、标度相同或可共用 L/M/U 的验证。
7. **WOD 特征构造核实。** 仓库已有 `scripts/rq014/build_wod_m3_anchors.py`，它能构造 32 项 WOD→M3 输入，并在 `tau` 结束 causal context；RQ016C 只消费其中 22 项数值和 4 项类别。但任务书只引用“列清单”，没有绑定这个 builder、列删减、版本/hash、缺失值口径或类别构造。RQ016C 的 HOWTO 只要求外部行提供同名列，并不证明外部行的语义一致。
8. **RQ012 边界核实。** `reports/knowledge/RQ012_onsite_event_annotation_readiness/decision.md` 确实把两人盲标取消，将人类判断证据压到 WOD-E2E + InterHub。它说明 RQ020 重要，但不增加 rated479 的独立性，也不替 RQ016C 建立 WOD 迁移效度。

## 主要设计结论

- “换参照”是方法变化，不是新样本。RQ016C 与 RQ014 M3 共享 RQ009 的目标定义和大部分建模结构；纯人筛选和删去三项类别特征并不会让 rated479 的评分摆脱先前选择。
- 支持门通过率不能按任务书第 167–168 行作二选一归因。RQ016C 同时改变了参照池、预测特征、支持门类别键和模型拟合；通过率高低不能单独区分“AV 混入”与“传感模态差异”。
- 支持门只是训练邻域相似性检查，不是 WOD 上区间覆盖的证明。P1/P3 比关闭门更可信，但仍需目标量一致和外部校准证据。

## 收尾问题

### Q1

**作为计算配方，部分正当；作为同一 rated479 上的新确认性主配方，不正当。** R04N 避开了 R10L 的已确认实现缺陷；CH-W25 是因果窗；H20、完整窗口和 terminal row 都有明确机械定义。这些性质使它适合作为可复算配方。

但四轴组合不是先于评分独立选定的：它属于 `RR3-R04N-CH-W25-H20-NMD_MEAN-RWS` 这条在 320 格/960 行中胜出的 selected cell。把效应量丢掉、只保留配方，不会丢掉选择事件本身。更换 L/M/U 也不会让同一评分样本成为新样本；而且 selected-recipe artifact 与 clean replay 尚未闭环。

**补救有两条，强弱不同：**最干净的是在完全未参与 RQ014 的新评分样本上检验；若只能使用 rated479，则只能把结果降为描述性，或预先冻结一个在每次置换中重跑全部历史选择步骤的 selection-aware 校准。事后切 rated479、只做当前四格 Holm、或再做 fold/LOO/LOCO 都不能恢复独立性。

### Q2

四格是一个有用的 **2×2 诊断表**，但不是一个充分的确认性检验家族。支持门开/关回答“受支持查询与数值外推是否一致”，NEX/NMD 回答“越界量与到中心的距离是否一致”；这两个轴值得保留。问题是关闭门的两格没有同等的推断地位，而历史选择家族也没有因此缩成四个。

**我的排序：P1 > P3 > P2 > P4。**

1. **P1：NEX + 门开。** 在目标量、90% 层和场景归约合同补齐后，它最贴近“超出人类区间”这一科学问题，应当是主格。
2. **P3：NMD + 门开。** 数值连续、并列较少，功效通常优于 NEX，但它把区间内差异也计为偏离，回答的是“离中心多远”，不是“是否越界”。
3. **P2：NEX + 门关。** 保留 RQ014 的原 primary 构念，可作历史可比诊断；但 L/U 在支持外没有覆盖承诺，不应给确认性 p 值。
4. **P4：NMD + 门关。** 它既依赖支持外的 M 与半宽，又最接近先前被评分选中的正面 cell，选择污染最大。它最容易被误读成“复现”，应排最后。

所以，把 P1 定为概念上的主格是对的；把四格都作为同等级推断端点是不对的。

### Q3

**不成立。** “本轮不搜索”只描述当前执行动作，没有描述配方的产生过程。R04N/CH-W25/H20/NMD_MEAN/RWS 已由同一 rated479 评分参与选择；换参照又是在看到 RQ014 的 NEX null 与 NMD positive 后提出的适应性动作。当前四格 Holm 只覆盖当前同时报告的四个 p 值，不覆盖历史 960 行选择，也不覆盖参照更换这一后续选择。

kinematics-only、shuffled IPV 和只在当前四格上取 max statistic，同样不能修复：它们的零分布把已选配方当成外生固定。要在同一数据上获得选择后可解释的 p 值，置换必须重放完整的选择算法；否则 p 值只能标注为 post-selection descriptive。

### Q4

**支持门关闭后的数值可以作为模型外推诊断报告，但不能作为已验证的人类越界量进入确认性检验。** `pre-OOD-mask` 只说明软件在遮罩前返回了有限数，不提供支持外的区间覆盖、中心准确性或半宽标度保证。

NEX 对 L/U 最敏感；NMD 即使主要依赖 M，也仍以未经验证的侧半宽归一化。把 P2/P4 与 P1/P3 并列给效应、CI 和 p，会给无效量套上合法外观。合理写法是单列“支持外模型外推”，给出覆盖比例和数值分布，不给确认性 p，不把它称为对人类范围的有效偏离。

### Q5

最可能的假阳性路径是 **P4 携带 RQ014 的 selected-cell 排序进入本轮**：执行方严格复现 R04N/CH-W25/H20/terminal row，使用 RWS 与 90% 层；RQ016C 因与 RQ009 共享目标定义和大部分模型结构，仍保留候选间相近的 NMD 排序；P4 又关闭支持门，因而最大限度保留场景数。随后同一 rated479 评分连接一次，P4 得到负相关并在当前四格 Holm 后通过。

这个结果可以同时通过任务书现有的全部检查：类别词表完整、数值有限、三候选齐全、预注册时间早于本轮连接、kinematics-only 较弱、shuffle 无信号、四格 max-stat permutation 通过、fold/LOO/LOCO 方向稳定。它仍然不成立，因为这些检查都把已由同一评分筛出的配方视为固定；没有任何一个检查重放 RQ014 的 960 行选择。内部删样稳定本来就是 selected cell 的入选条件之一，因此再次通过并不提供独立证据。

### Q6

**有：缺少一个冻结的 WOD→RQ016C 测量与归约合同，导致阶段二产物没有唯一解释。** 至少三件事未定义：

- 用 RQ016C 的 80/90/95 哪一层定义 L/U；任务书给出三个输出层，却没有明确写 `alpha=90`。
- 为什么五行未来目标的 L/M/U 可以标准化 2.5 s 因果窗 terminal-row IPV；当前证据显示两者定义不同。
- 支持门是逐 tau、逐候选判定；当三候选或不同 tau 的门结果不一致时，是整场景弃权、整候选弃权、取三候选公共 tau，还是各自对剩余 tau 求均值。四种规则会产生不同的场景数和偏离向量。

在这些规则冻结前，`stage2_envelope.json` 中的 P1–P4 不是“不够漂亮”，而是没有唯一测量对象。

### Q7

我用任务书数字隐含的近似口径独立复核：场景独立、普通相关系数、Fisher z、80% 功效、双侧检验。公式为

`rho_min(n, alpha) = tanh((z_(1-alpha/2) + z_0.80) / sqrt(n-3))`。

在未校正双侧 `alpha=0.05` 下，任务书三个例子是对的：n=42 为 **0.421**，n=100 为 **0.277**，n=150 为 **0.227**。但它们不是四格 Holm 下的保守数字。Holm 最小 p 的首步阈值是 0.0125；某一格实际落在第几顺位事前未知，因此应至少报告如下范围：

| 每格场景数 n | Holm 首步 alpha=.0125 | Holm 第四步 alpha=.05 |
|---:|---:|---:|
| 42 | 0.489 | 0.421 |
| 75 | 0.374 | 0.319 |
| 100 | 0.327 | 0.277 |
| 150 | 0.269 | 0.227 |
| 200 | 0.234 | 0.197 |
| 300 | 0.191 | 0.161 |
| 479 | 0.152 | 0.128 |

按首步 `alpha=0.0125` 保守口径，识别 `|rho|=0.50/0.40/0.30/0.25/0.20/0.15` 分别约需 **40/66/120/174/275/492** 个独立场景。rated479 即使零损失，也达不到对 0.15 的 80% 功效。

任务书还留下两个功效歧义。第一，方向假设像单侧检验，但其示例数字来自双侧 0.05；若用未校正单侧 0.05，n=42/100/150 的数会变成 0.378/0.247/0.202。第二，若最终统计量是 RWS（每场景仅三候选、含大量并列）并用场景置换或 bootstrap，普通 Fisher-z 只是理想化近似；正式最小效应应按冻结的 RWS、并列结构和置换规则在盲态 predictor 上校准。

**“每格报最小效应”不够防止把零结果写成“无关联”。** 它只描述拒绝零假设的能力，不证明效应接近零。还必须预先给出科学上最小重要效应，并用 CI/等效性规则限定结论；例如只有当整个 CI 落在预先定义的无实质意义区间内，才可排除大于该阈值的关联。否则只能写“本样本未提供明确关联证据，且小于表中阈值的效应缺乏辨识力”。

### Q8

**`NO_GO`。**

**单一最重要修改：把阶段三改到一批从未进入 RQ014 搜索的新评分样本上；rated479 只保留为描述性开发集。**

## 本轮范围：只做两件，都在分层抽样上

**S1 — 平价门**：证明 log 域改写与现行连乘**数学等价**。

关键事实（已确立）：`var_i = [∏_k φ(d_ik)]^{1/n}`，取对数后
`log var_i = −log(σ√2π) − MSE_i/(2σ²)`，首项在归一化时约掉，
故现行计算恒等于 `w = softmax(−MSE_i/(2σ²))`。连乘是绕路，也正是下溢之处。

**因此平价检验不需要重解虚拟轨迹**：对抽样帧解一次拿到逐候选 MSE，
再用同一组 MSE 分别算"现行连乘"与"log 域"两种权重，对比即可。
这把数值问题与求解器问题彻底隔开，成本极低。

判据：两者在**未下溢**的帧上逐位差 ≤ 1e-12；在**已下溢**的帧上现行走兜底而新法给出
非均匀权重（这正是要修的病）。并证明新法下兜底分支**不可达**。

**S2 — 机制拆分**：把零值成因拆成 D1/D2/D3/D4，给出各自比例。

```
D0  NOT_ATTEMPTED   warm-up 占位（ipv_error = 1.0，估计器从未运行）
D1  数值下溢         乘积在开 1/n 次方之前下溢 → 触发均匀兜底
D2  当前网格与模型下真平坦   候选间 MSE 差异本就极小
D3  模型失配         最小 MSE 本身很大（阈值须先冻结并登记 SHA，再跑分类）
D4  求解器失败
```

**这是本轮最有价值的产出**：它回答"那四成零值里，有多少是**修得好的**"。
若 D1 占主导，log 域改写能直接救回大量样本；若 D2 占主导，问题在网格/模型，
改数值没用——这个分叉直接决定后续要不要申请全量重跑预算。

下溢临界 RMS（已算出）：n=5 为 1.6915 m（subnormal）/ 1.7336 m（舍入为 0）；
n=11 为 1.1470 / 1.1752 m。

# RQ017 两轮独立双盲复审报告

执行前对任务书做了两轮独立双盲复审。每轮两位 agent：**A 号**从方案入手逐条审；
**B 号**两阶段，阶段一禁止打开方案、先从代码与数据独立推导，阶段二才对照。
两份 prompt 的收尾问答逐字节相同（第一轮各 1,172 字节、第二轮各 1,209 字节），便于比对分歧。
双方互相禁读对方产物与日志；B 号另禁读 `START_HERE.md`、`STUDIES.md`、`main_workflow.log`、
知识层 README、`commander_notes.md` 等转述型文件——这些读了等于隔一层读到别人的结论。
第二轮还把第一轮的两份报告也列入双方禁读，使其独立评估 v3 本身。

| 文件 | 轮次 | 角色 | 审的对象 |
|---|---|---|---|
| `round1_A_from_plan.md` | 第一轮 | A（从方案入手） | 任务书 v2（本机版） |
| `round1_B_blind.md` | 第一轮 | B（两阶段致盲） | 同上 |
| `round2_A_from_plan.md` | 第二轮 | A（从方案入手） | 任务书 v3（HPC 版） |
| `round2_B_blind.md` | 第二轮 | B（两阶段致盲） | 同上 |

四份的 Q8 结论均为 `GO_WITH_CHANGES`。

**第一轮的主要产出**：两位复审**独立收敛**于同一条意见——把输入/测量合同提到 canary 之前、
写成会 FAIL 的断言。理由是输入适配层（行位置窗口、ego/counterpart 方向、参考线）接错，
仍会产出七个有限 MSE、权重和为 1、门判据可复算、`ipv_log` 恒等式成立的结果，
**既有检查全部通过**，但解的是错的行。据此产出 v3 的第 3 节。

**第二轮的主要产出**（主要由 A 号给出，B 号在 PYTHONPATH/pydeps/sacct 上重合）：
v3 把 HPC wrapper 写成了文字模板而非可执行合同——冻结 env 没有 pyarrow、
v3 的 sbatch 片段缺 `PYTHONPATH`、环境同源只要求「记录并比对」太软、
机制二交叉未限定连接列（现成打分脚本整表读取，会拉进旧估计器通道与目标值）。
据此产出执行版 v4。

**注意**：第一轮的两份报告文件名仍带 `RQ016D` 前缀，是因为复审执行时该轨道尚未分配
RQ017 编号；内容即本轮任务书的复审，未作改动。

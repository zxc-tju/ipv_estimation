## 1. 这项工作要解决什么问题

最终目标是**在线验证**：判断一辆自动驾驶车表现出的社会交互倾向像不像人。
手稿把它组织成一条**社会判断阶梯**：

```
人类参照范围 → 条件性社会非典型 → 人类不认可的行为 → 有害交互
```

前两级已完成并被接受；第四级在 OnSite 上做过（RQ018/RQ019）。
**第三级「人类不认可」只有 WOD-E2E 能做**——它是唯一带释出人类偏好评分的数据集。

这一级支撑全文最核心的区分：**「社会非典型」不等于「社会不合适」**。

## 2. 本轮用的判据（全部已冻结，且从未见过 WOD 的任何评分）

这是 v4 与 v3 最根本的区别：**判据不是从 WOD 评分里选出来的，是在别的语料上独立冻结的。**

| 组件 | 来源 | 冻结于 |
|---|---|---|
| 估计器配置 | `configs/ipv_sigma01_exact.json`（受保护文件） | RQ015 前 |
| 求解器 | `.codex-fleet/rq015b-repair/work/run_b2_rq015b.py` 的 `loads_array` / `solve_anchor_task` | RQ015B |
| 候选网格 | `legacy7_pi_over_8`，K=7，`[-3..3] × π/8` | RQ015 |
| **机制一** | `log_score = −mse/(2σ²)`，σ=0.1；`w_log = softmax`；`mse_spread == 0`（精确浮点相等，**不得用 isclose**）→ `NO_IPV_EFFECT`；`max(w_log) < 0.20` → `NEAR_UNIFORM`；否则 `ipv_log = Σ(candidate_ipv × w_log)` | RQ015K |
| **机制二** | RQ016C 纯人-人 envelope + 支持门 | RQ016C（2026-08-04，InterHub 2,442,625 行纯人-人） |
| **目标位置** | `target_pos = anchor_pos + TARGET_FINAL_OFFSET`，`TARGET_FINAL_OFFSET = 6` | RQ009 建 envelope 时的同一定义 |

**`θ = 0.20` 是政策阈值，不是数据断点。不得调参、不得做阈值扫描。**

### 为什么这套配置对 WOD 评分是前瞻的

它在 InterHub 上冻结、在 OnSite 上执行（RQ017/RQ018/RQ019），
**全过程从未读取过 WOD-E2E 的任何评分**。因此对 WOD 评分而言它是一个**外来的、预先固定的判据**——
这正是 v3 缺的东西。

### 为什么估计量是对齐的

RQ016C 的 envelope 目标列是 `target_ipv_future`，其定义为估计器在
`anchor_pos + TARGET_FINAL_OFFSET` 的读数（`build_features.py`）。
RQ017 的 materializer 用的是同一个 `TARGET_FINAL_OFFSET = 6`。
**照抄这一条，`[L, U]` 才是被检验量的区间。**

## 4. 阶段 A：评分盲的可行性与迁移诊断

**这一阶段完全不碰评分，且本身就有独立价值。**

### 做什么

1. 用 RQ014 的评分盲特征管道，为 WOD-E2E 的 rated479 场景产出
   **RQ016C 特征合同要求的 22 个数值 + 4 个类别 context 特征**
   （合同：`reports/studies/RQ016C_human_only_envelope/RQ016C_1_human_only_envelope_20260804T005716Z_7480c173/envelope_model/feature_contract.json`）

   （`status` / `reason_code` / `ipv_log`），目标位置用 `TARGET_FINAL_OFFSET = 6`
3. 用 RQ016C 持久化模型打分（**只加载，不重新拟合**），得到 `lo_90 / hi_90 / width_90`
   与支持门判定

   ⚠ pkl 不在仓库内（164 MB，gitignore），在
   `.codex-fleet/rq016c-human-only-envelope/work/H2/envelope_model/rq016c_h2_envelope.pkl`

4. **先做类别词表覆盖断言**——RQ016C 自己踩过这个坑：H1 那轮因训练词表无 `AV`，
   产物对外部行可能 0 命中。任何未覆盖的类别值必须显式报出，不得静默丢弃

### 必须报出的诊断（本阶段的主要产出）

| 数字 | 为什么重要 |
|---|---|
| **机制一通过率** | 与 OnSite 的 55.2971%、InterHub 的 70.3001% 对照 |
| **机制二支持门通过率** | **谁都不知道的数字。** RQ010B 实测 M3 在 WOD 上 ≤15%；RQ016C 若明显更高，说明纯人-人重建改善了迁移；若同样低，说明问题在传感模态而非 AV 污染。**两个方向都是可报告的结果** |

**以场景计数，不以候选行计数。两者分开报。**

### 停止条件

**若两门都过、且三候选完整的场景数 < 60，停下报告，不进入阶段 B。**

理由（功效）：单次预先指定检验在 n=60 时 80% 功效只能识别 ρ≈0.35；
n=100 约 ρ≈0.28；n=150 约 ρ≈0.23；n=305 约 ρ≈0.16。
低于 60 时，任何零结果都只能说「不可识别」，做了也不回答问题。

**停在这里不是失败。** 阶段 A 的迁移诊断本身就是可发表的方法学结果，
且它直接给 C3-bnd（envelope 迁移非无条件）提供跨传感模态的证据。

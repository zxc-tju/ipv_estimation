# RQ029 v1：面向论文当前记录的合成微观数据微调

状态：`EXECUTED / PASS_HARD / PARTIAL_SOFT_MATCH`

## 1. 目的

RQ029 v0 已生成上海 20×15 合成轨迹并精确匹配 RQ022 聚合边际，但其微观依赖结构采用场景内
可交换抽样，原始对手指标又取最近背景车，因此部分 bootstrap 区间和原始运动学派生量与论文当前
记录仍有差距。本轮保留 v1 包不动，生成 `v2_paper_aligned`，使合成数据更接近论文当前
`main.tex` 和 `claims_register.md` 所打印的记录。

“更接近”不等于“恢复真实数据”。真实 300 个运行、186 个交互 case 与逐时刻结果的对应关系不在
仓库中，无法由聚合值唯一反演。v2 继续标为 `SYNTHETIC_NOT_OBSERVED`。

## 3. 硬约束

1. 上海 20 名驾驶员 × 15 场景、300 runs、0 缺场景；背景与 v1/T11 完全一致，主车路径和速度扰动
   不改。
2. candidate/gate1/both、80/90/95 三档计数、15 个场景的 `n_both/n_flagged`、六项签名点估计与
   分子分母继续逐项精确一致。
3. 论文新增记录须复算一致：人类场景率 1.7%–12.4%，AV 场景率 2.7%–17.4%，AV/人类比值
   1.95、场景 bootstrap 95% CI 1.62–2.39、20,000/20,000 重抽样高于 parity。
4. 两个人类 ego-margin 点只有点估计，v2 不生成、补写或暗示其区间。
5. 不读取 RQ007 held-out、RQ014 致盲字段、官方得分、伤害或偏好端点；不改论文仓库。

## 4. 微调方法

- 原始对手：用 T11 标准化时序中每个上海场景已经固定的交互对手 ID，不再逐帧选最近背景车。
- 原始窗口：从指定对手速度序列差分得到加速度，按论文固定 3 秒（31 帧）重算速度下降、速度极差、
  `<−3 m/s²` 帧计数；从合成 ego 与指定对手的相对运动重算未来最小 TTC。
- 微观异质性：在所有硬边际不变的条件下，引入受正则约束的 synthetic driver/run effects 和短块状
  flag 分配；以论文 CI 端点距离为软损失，同时惩罚病态集中、极端单元率和无意义 pseudo-case。
- 签名：优先选择原始 3 秒窗口指标接近目标的行，再做秩保持边际投影；`_raw` 与 `_calibrated`
  始终分列。若必须构造 186 个 case，只能命名为 `synthetic_case_id`，按场景内相同背景事件的时间块
  跨驾驶员归组，且说明这只是可追溯的合成聚类，不是原始 case 映射。

## 5. 验收

- 五个合成 CI 的加权端点损失低于 v1，且与论文相同地排除/不排除零或 parity；CI 数值不要求精确
  等于四舍五入后的目标，未达到容差的项目必须逐项披露。

## 为什么留着这些文书

因为这个方向已经烧掉四版任务书和三轮双盲复审，而**答案在开工之前就存在于仓库里**：
RQ010B 已于 2026-07-03 用预注册、评分盲、独立复审加红队的方式做过同一个检验，
结果是有界 null（方案① n=75，ρ=+0.148 符号与假设相反，max-stat permutation p=1.0）。

留下这批文书是为了**防止第五次重开**。任何人想重启 WOD 人类偏好方向之前，
先读 `decision.md`，再读 RQ010B 的报告。

三轮复审全部返回 `NO_GO`。第三轮的两条核心理由：

- **A 审**：那套 IPV 配置（R04N / CH-W25 / H20 / terminal row）是在**同一批评分**上做
  320 格、960 行筛查选出来的。换参照模型没有换结果数据，也没有消除配置选择对该批评分的依赖，
  因此不能解释为新的确认性检验。
- **B 审**：缺测量合同，若干比例没有唯一分母或唯一语义；且任务书只给了含评分的
  `frames.tfrecord` 路径，未给 score-stripped 输入的 manifest/hash 绑定。

两位审稿人都指出：**评分盲的描述性诊断部分本身有价值**，他们否定的只是
「前瞻的人类不认可验证」这一定性。

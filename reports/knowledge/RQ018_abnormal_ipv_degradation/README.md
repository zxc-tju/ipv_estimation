# RQ018：异常 IPV 与行为劣化是否存在对应关系（知识层）

## 问题

最终目标是**在线验证**：判断一辆自动驾驶车表现出的社会交互倾向像不像人。判定由两道串联
弃权机制构成——**机制一**判断某一帧的 IPV（Interaction Preference Value，表示交互倾向的
标量）数值是否携带七个候选之间的判别信息；**机制二**用人类参照分布判断当前情境是否有
足够人类样本可比。

RQ017 已在自动驾驶车数据上算出机制一判据。**RQ018 问的是**：OnSite 数据集在整个研究中的
职责是论证「交互事件的劣化与不合理的 IPV 表达是否存在明确对应关系」——当 IPV 超出人类
合理范围时，行为有没有呈现出可测的不合理倾向。

正向探索，不做闭环验证，不留出数据集。

## 结论

**B1 —— 超出人类参照的 IPV 表达显著压缩了安全裕度的整体分布，但不制造极端危险情形。**

IPV 低于该情境人类参照下界（**比人类更激进**）的帧，后续最小 TTC 的分布**整体左移**：
中位 **7.51 s** 对区间内 **8.81 s**（−14.8%），75% 分位 **12.75 s** 对 **22.38 s**（−43.0%）。
`log(1+TTC)` 上的 case 聚类系数 **−0.2311**、95% CI [−0.3495, −0.1126]、p=0.0002；
80/90/95 三层与两个窗口方向一致，并通过 200 次标签置换与 200 次安慰剂对照。

**这一偏移发生在分布的主体与安全端，不在危险端。** 25% 分位两组几乎相同（4.105 对 4.089），
危险阈值以下的帧占比一致**更低**：TTC<1 s 为 1.37%(25/1,819) 对 2.62%(229/8,739)；
TTC<2 s 为 5.28%(96/1,819) 对 9.85%(861/8,739)；TTC<3 s 为 12.53%(228/1,819) 对 16.90%(1,477/8,739)。
case 层 bootstrap 1,000 次：TTC<2 s 占比差 −0.0457，95% CI [−0.0696, −0.0227]；
TTC<3 s 差 −0.0437，CI [−0.0805, −0.0043]，均不含 0。

**PI 解读（2026-08-05，定性依据）**：IPV 是社会交互倾向的属性，**本就不是安全代理指标**，
因此它的越界不带来更极端的危险情形是合理的、符合预期的。有价值的信息在另一面——
它**把原本比较安全的情形变得没有那么安全**，即实实在在压缩了整体交互的安全裕度。
不良的交互偏好表达确实影响安全，但作用形态是**分布压缩**而非尾部恶化。

**因此「未观察到更高风险」是本结论的边界条件，不是本结论本身。**
引用时不得只截取后半句。

**B2 —— 上侧越界（比人类更合作让行）没有任何劣化对应。** `log1p(TTC)` 上侧系数 −0.0146，
p_case=0.8564。

**B3 —— unit 级非安全子分数不形成一致模式。** 245 个 `analysis_set` unit 中 225 个曝露有定义；
效率呈负相关、协调性呈正相关、舒适与合规区间跨零。与 RQ012B 标注的官方子分数强机械吸收
（以非安全子分数为基线时 R²=0.969）一致。

**B4 —— 事故类结果功效不足，无法回答。** 全 267 个 unit 中 `official_safety < 100` 仅 21 个、
`collision_intervention_deduction_any != 0` 仅 18 个。

## 关键澄清：IPV 符号语义（下游极易读反）

`src/sociality_estimation/core/agent.py:1193` 为
`util = cos(ipv) × 自身代价 + sin(ipv) × 交互代价`，候选网格 `[-3..3]×π/8`。
**IPV 越大 = 越看重对方代价 = 越合作让行；IPV 越负 = 反向压制对方 = 越竞争激进。**

**下侧越界是「比人类更激进」，不是「更消极」。**

**下侧越界 ≠ `IPV < 0`**：判据是 `ipv_log < lo_90`，`lo_90` 随情境变化（中位 −0.5427）。
下侧越界 1,998 行确实全部 `ipv_log < 0`，但区间内另有 3,611/9,401 = 38.41% 的行也是负 IPV
却未越界——人类在那些情境下同样取负值。

## 效度边界

1. **不得使用因果表述**；描述性关联，设计不支持因果。
2. **不得把「TTC 中位更短」读成「更危险」**（见 B1）。
3. **主口径无结果**：任务书指定 `future_min_ttc_s`，该原始尺度上 TTC 全部不显著
   （p_case 0.31–0.37）；`log1p` 为事后变换。
4. **TTC 缺失与曝露相关**：上侧 13.70%、下侧 8.96%、区间内 7.04%；偏倚方向使 B1 只会被低估。
5. **结果变量互相矛盾**：同为下侧越界，最小距离方向相反且显著（+1.0396，p_case=0.0064）。
6. **多重比较**：共 288 个 p 值；标签置换 p=0.0149 承受不了多重校正。
7. 不对任何车辆或队伍作判断。

## 与 RQ012B 的关系

RQ012B 冻结结论 `RQ012-KC-HARM-NULL`（旧 RQ009 M3 参照，含 10.9009% 自动驾驶车目标值；

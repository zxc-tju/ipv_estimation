# RQ018-1：异常 IPV 与行为劣化的关联性正向探索（执行记录）

执行日期：2026-08-04｜基线提交：`276cf4c`｜执行方：单个 codex agent（A1，本机）｜监督方：Claude

## 这一轮在整个研究里的位置

最终目标是**在线验证**：判断一辆自动驾驶车表现出的社会交互倾向像不像人。判定由两道
串联的弃权机制构成——**机制一**判断某一帧的 IPV（Interaction Preference Value，
表示交互倾向的标量）数值是否携带七个候选之间的判别信息；**机制二**用人类参照分布
判断当前情境是否有足够人类样本可比。

RQ015 冻结机制一，RQ016C 建好纯人-人参照分布，RQ017 首次在自动驾驶车数据上算出机制一判据。
本轮问的是下一步：**当自动驾驶车的 IPV 超出人类合理范围时，它的行为有没有可测的劣化。**

这是**正向探索**，目的是判断线索是否存在，不做闭环验证，不留出数据集。

## 结论

**超出人类参照的 IPV 表达显著压缩了安全裕度的整体分布，但不制造极端危险情形。**

**PI 解读（2026-08-05）**：IPV 是社会交互倾向的属性，本就不是安全代理指标，因此越界不带来更极端危险是符合预期的；有价值的信息是它把原本比较安全的情形变得没有那么安全，即压缩了整体交互的安全裕度。「未观察到更高风险」是本结论的**边界条件**，不是结论本身。

在 OnSite 数据上，自动驾驶车 IPV 低于该情境人类参照下界（即**比人类更激进**）时，
其后续最小 TTC 的分布整体左移（中位 **7.51 s** 对区间内 **8.81 s**，−14.8%；75% 分位 **12.75 s** 对 **22.38 s**，−43.0%），
**但危险阈值以下的帧反而更少**：

| 阈值 | 下侧越界 | 区间内 |
|---|---:|---:|
| TTC < 1.0 s | 25/1,819 = 1.37% | 229/8,739 = 2.62% |
| TTC < 2.0 s | 96/1,819 = 5.28% | 861/8,739 = 9.85% |
| TTC < 3.0 s | 228/1,819 = 12.53% | 1,477/8,739 = 16.90% |

case 层 bootstrap（1,000 次）：TTC<2 s 占比差 −0.0457，95% CI [−0.0696, −0.0227]；
TTC<3 s 差 −0.0437，CI [−0.0805, −0.0043]。两者均不含 0。

**分布左移来自安全端长 TTC 的减少，不是危险端的增加。** 25% 分位两组几乎相同
（4.105 对 4.089），差异全在中位与上尾。

对 PI 三个问题的回答：

1. **是否造成危险**——**未制造极端危险情形（危险阈值以下的帧反而更少），
   但显著压缩了安全裕度的整体分布**。按 PI 定性，后者才是本轮的有效信息。
2. **是否更容易发生事故**——功效不足，答不了（全 267 unit 中 `official_safety < 100`
   21 个、`collision_intervention_deduction_any != 0` 18 个）。
3. **是否存在各方面劣化**——unit 级四个非安全子分数无一致模式（效率负相关、
   协调性正相关、舒适与合规区间跨零）。

## 关键澄清：IPV 的符号语义

从受保护源码确认（`src/sociality_estimation/core/agent.py:1193`）：
`util = cos(ipv) × 自身代价 + sin(ipv) × 交互代价`。因此
**IPV 越大 = 越看重对方代价 = 越合作让行；IPV 越负 = 反向压制对方 = 越竞争激进。**

**下侧越界是「比人类更激进」，不是「更消极」。**

下侧越界**不等价于 `IPV < 0`**：判据是 `ipv_log < lo_90`，而 `lo_90` 随情境变化
（中位 −0.5427，5–95 分位 [−1.1033, −0.0518]）。实测下侧越界 1,998 行全部 `ipv_log < 0`，
**但区间内还有 3,611/9,401 = 38.41% 的行也是负 IPV 却未越界**，因为人类在那些情境下同样取负值。

## 效度边界（引用本轮结果必须一并带上）

1. **不得使用「导致」等因果表述。** 本轮为描述性关联，设计不支持因果。
2. **不得把「后续 TTC 中位更短」读成「更危险」。** 危险阈值以下的帧占比方向相反，
   且经 case 层 bootstrap 确认稳健。
3. **主口径无结果。** 任务书指定的结果变量是 `future_min_ttc_s`；在该原始尺度上
   TTC 三种曝露、两个窗口全部不显著（p_case 0.31–0.37）。`log1p` 是执行方看到数值病态
   （最小正接近率 4.915e-09 m/s 造出 7 行 TTC > 10⁶）后事后加的变换。
4. **TTC 缺失与曝露相关**：上侧 13.70%、下侧 8.96%、区间内 7.04%。缺失的是全窗口都在
   远离即最安全的帧；偏倚方向使上表结论只会被低估，不会被夸大。
5. **结果变量互相矛盾**：同为下侧越界，最小距离方向相反且显著
   （fixed_3s 系数 +1.0396，p_case=0.0064，即距离更大）。
6. **多重比较**：产物中共 288 个 p 值。`p_case=0.0002` 大致可承受 Bonferroni，
   但用于背书的标签置换 p=0.0149（200 次中 3 次）不能。
7. 本轮**不对任何车辆或队伍作出判断**。
8. 禁用 `estimability` 与「测出/未测出 IPV」表述。

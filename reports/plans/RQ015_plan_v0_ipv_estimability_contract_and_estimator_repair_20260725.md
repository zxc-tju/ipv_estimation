## 0. 一句话

在把任何 IPV 结论（正面或负面）继续往前推之前，先把"这一帧到底有没有测出 IPV"
这件事变成一个显式的、可审计的、贯穿全项目的状态量；并修复导致"无信息"被静默写成
"中性 0"的估计器缺陷。

## 1. 研究问题

**RQ015**：IPV 估计在多大比例的样本上实际不可辨识？这种不可辨识是数值实现缺陷还是
情境固有性质？把不可估计显式化并修复实现之后，项目既有的一批阴性结论是否仍然成立？

三个子问题，对应三个阶段：

- **RQ015-A（测量）**：现有全部 IPV 产物的可估计性画像是什么？不可估计能否被回溯识别？
- **RQ015-B（修复）**：把概率空间似然改为 log 域、把均匀兜底改为显式弃权之后，
  可估计率、IPV 分布、下游包络与 M3 会怎样变化？
- **RQ015-C（重估）**：在可估计子样本上，RQ010B / RQ011B / RQ012B / RQ003 的阴性
  是否仍然成立？

## 2. 触发证据（已实测，rating-free，只读）

数据源：`data/derived/interhub/.../03_features/target_hw4/sigma01_hw4_ipv_timeseries.csv`
（sigma=0.1 全量重跑），7,391,962 个 agent-值；判据 `ipv_error = 1 − √Σw²`（权重集中度）。

### 2.1 零值规模

- **|IPV| < 1e-9 占 43.71%**；RQ009 目标变量（ego rolling IPV @ horizon）上为 42.24%，一致。
- 零值行中 **92%** 的 `error ≥ 0.61`（权重近乎均匀）；其中 **32.4%** 精确等于
  `1 − 1/√7 = 0.622036`，即 `sum(var)==0` 的均匀兜底分支。
- 真正"自信的零"（one-hot 落在 k=0，error=0）仅 1,703 行 = 零值的 **0.053%**。

### 2.2 全样本可估计性画像

以有效候选数 `K_eff = 1/(1−error)²` 表示（K=7 时上限 7）：

| 判据 | 占全部值 | 解释 |
|---|---|---|
| `error ≥ 0.61`（K_eff ≥ 6.6） | **54.5%** | 七个候选几乎没被区分 → 实质无信息 |
| `error ≤ 0.5`（K_eff ≤ 4） | **23.2%** | 有实质辨识力 |
| `P(IPV=0 \| error ≥ 0.61)` | **73.8%** | 不可辨识与零值高度重合 |

### 2.3 按数据源

| 数据源 | values | zero% | err≥0.61 | err≤0.5 | K>7 异常 |
|---|---:|---:|---:|---:|---:|
| waymo_train | 3,917,992 | **48.86%** | 55.40% | 27.42% | 4.74% |
| av2 | 358,398 | 42.57% | 57.21% | 9.61% | 5.37% |
| nuplan | 1,951,196 | 37.47% | 57.86% | 10.35% | 3.07% |
| lyft | 1,164,376 | 37.20% | 45.29% | 34.50% | 3.51% |

Waymo 零值率最高（48.9%），而 WOD-E2E 属 Waymo 域——外部验证路线恰好撞在最差的域上。

### 2.4 机制（已从源码确认）

`src/sociality_estimation/core/agent.py::cal_traj_reliability`：

```python
var[i] = (∏ (1/σ√2π)·exp(−d²/2σ²))^(1/n)      # σ = 0.1 m，概率空间
if sum(var):  weight = var / sum(var)
else:         weight = np.ones(K) / K           # 均匀兜底
subject.ipv = sum(ipv_range * weight)           # 对称网格 ⇒ 精确 0
subject.ipv_error = 1 - np.sqrt(sum(weight**2)) # ⇒ 0.622036
```

两条不同性质的路径产生同一个数字 0：

- **D1 数值下溢**：最优候选轨迹 RMS 偏差 > 约 3.8 m 时全部 var 下溢为 0 → 走兜底分支。
  这是实现缺陷。
- **D2 固有不可辨识**：七个候选模拟出的轨迹几乎相同（该情境下社会性参数对轨迹无杠杆）
  → var 近乎相等。这是有科学含义的真实性质。

当前实现把 D1 与 D2 都写成 `ipv = 0`，且**无法从产物中区分**。

### 2.4b 单位很关键：帧级 vs case 级（2026-07-25 追加实测）

§2.2 的 23.2% / 54.5% 是**帧×agent 级**。按 case 聚合（38,228 个 case，平均 96.7 帧）：

| case 级判据（`err≤0.5` 记为可估计值） | cases | 占比 |
|---|---:|---:|
| 至少 1 个可估计值 | 36,702 | **96.01%** |
| 至少 5 个 | 34,125 | **89.27%** |
| 至少 10 个 | 31,638 | 82.76% |
| 至少 20 个 | 26,832 | 70.19% |
| 至少 5 个强可估计（`err<0.3`） | 28,013 | 73.28% |
| 完全没有可估计值 | 1,526 | 3.99% |
| case 内可估计比例 ≥50% | 3,303 | 8.64% |
| case 内可估计比例均值 | — | 23.37% |

**结论：语料在 case 级并未废掉。** 约 90% 的 case 含有 ≥5 个可估计帧，仅 4.0% 完全无可估计值。
真实图景是：**每个 case 内部只有约四分之一的帧可估计**，可估计性在 case 内是稀疏分布的。

因此危害是**单位依赖**的：

- **帧/锚点级产物直接受损**：RQ009 M3 的 6.4M 锚点训练与包络、RQ014 的逐 tau 滚动读数、
  RQ011B 的时刻级监控——约一半的行不带信息；
- **episode/case 级产物受损较轻**，但前提是摘要只在可估计帧上计算。若摘要对全部帧
  取平均，则被 ~55% 的零值稀释向 0——这正是 **RQ007-KC-C3** 已量化的现象
  （all-valid 与 interaction-active 摘要均值相差 ≈0.26 rad，约 22% 的 case 严格符号翻转；
  可估计性加权后降至 ≈7%）。RQ015 应沿用并扩展该加权方案，不另起炉灶。

### 2.4c 可估计性并非主要由接近程度决定（追加实测）

按两车瞬时距离分箱（帧×agent）：

| 距离 | values | zero% | err≥0.61 | err≤0.5 |
|---|---:|---:|---:|---:|
| <5 m | 278,522 | 26.34% | 33.67% | **44.50%** |
| 5–10 m | 1,197,626 | 43.13% | 54.86% | 23.91% |
| 10–15 m | 2,218,356 | 42.72% | 54.98% | 22.32% |
| 15–20 m | 1,480,730 | 45.08% | 56.00% | 21.23% |
| 20–30 m | 1,332,242 | 46.29% | 55.25% | 22.58% |
| 30–50 m | 665,526 | 47.83% | 56.22% | 21.82% |
| ≥50 m | 218,960 | 45.76% | 55.70% | 21.34% |

只有 <5 m 一档明显改善，但它仅占全部帧的 3.8%，且只贡献约 7% 的可估计值；
5 m 以外基本平坦（可估计率约 22%，与距离无关）。

**含义**：可估计性**不是**简单的"离得近才测得到"。决定某一帧能否估计的因素目前未知，
这使"什么预测了帧级可估计性"成为 Phase A 必须回答的问题——答案决定了不可估计
是可修的采样/实现问题，还是 IPV 模型在该类轨迹上的固有识别极限。
（注：这与 RQ007-KC-C1「主要由接近程度驱动」不矛盾——RQ007 比较的是交互机会窗内外，
而机会窗大体就是近距离帧；但本表说明窗外仍有大量可估计帧。）

### 2.4d 与历史 sigma 修正的关系：**不是重复劳动**（口径区分，必读）

档案中已有"sigma 修正解决了零值问题"的记录，且数字显著。**该记录属实，但与本 RQ 针对的
不是同一个口径**，若不加限定会使读者误认为问题已解决、进而误判 RQ015 为重复劳动。
两个口径必须分开：

| 口径 | 定义 | sigma 修正的效果 | 现状 |
|---|---|---|---|
| **case 级全零** | 整段 case 的 IPV 全部为 0 | `σ=0.02` 时 7,318/38,228 = **19.14%**；`σ=0.1, hw=10` 降至 17/38,228 = **0.044%**；M3 实际使用的 `σ=0.1, hw=4` 为 43/38,228 = **0.112%** | **已基本消除** |
| **锚点/帧级零膨胀** | 单个锚点 `\|IPV\|<1e-6` | 未针对、未测量 | **仍为 42.87%**（M3 训练集 1,096,693/2,558,374；测试集 42.24%；四折合计 2,742,214/6,397,266；字面精确 0 为 21.89%，差额是 1e-17 量级浮点残差） |

结论：**sigma 修正消除的是"整段 case 崩塌"这一灾难性故障，它对其目标是有效的；
但它没有、也未曾声称触及锚点级零膨胀。** RQ015 处理的是后者。目标列无缺失或非有限值。

### 2.4e sigma 修正史构成 D1（数值缺陷）的直接证据

上表同时是一次**非计划的剂量-反应实验**：高斯核从 `σ=0.02` 加宽到 `σ=0.1`，
case 级全零率下降约 **170 倍**（19.14% → 0.11%）。核越窄越容易在概率空间下溢，
这正是 §2.4 中 D1 机制的预测方向。

因此可以断言：**D1 是真实存在且量级很大的成分**，而非理论隐忧。但 `σ=0.1` 只是
把下溢悬崖推远（临界点约为最优候选轨迹 RMS 偏差 3.8 m），并未拆除它——
锚点级 42.87% 的零膨胀即是悬崖仍在的证据。

这直接支撑 Phase B 的技术路线：log-sum-exp **拆除**悬崖（下溢不再可能），
而不是像调 σ 那样只把它推远一点。据此，Phase B 对 D1 类零值的消除预期是高的；
残留部分即可归因于 D2（固有不可辨识），从而完成 §3-H2 的定量拆分。

### 2.5 待查异常

**9.47% 的零值行 `error > 0.62204`**，超过 K=7 的理论上限，说明时间序列中混入了
候选网格数不同（K≥9）的行。同一份产物混用不同网格必须查清，可能影响所有以
`ipv_error` 为条件的分析。

## 3. 假设与预期（预登记）

- **H1**：`error ≥ 0.61` 的样本上，IPV 取值与任何外部结果的关联应显著弱于
  `error ≤ 0.5` 的样本（若不然，则说明关联并非来自 IPV 的社会性内容）。
- **H2**：改 log 域后，D1 类零值大幅减少；D2 类零值基本不变。
  二者的相对比例即"缺陷 vs 固有"的定量拆分。
- **H3（探索性，不预设方向）**：在可估计子样本上重估既有阴性，效应量会上升
  （衰减假说）或保持不变（真实无效应假说）。两种结果都要如实登记。

**明确禁止**：以"重估后效应变强"为目标去调节可估计性阈值；阈值必须在看到任何
重估结果之前冻结（§5）。

## 4. 阶段与交付物

### Phase A — 回溯可估计性打标（无需重算，成本最低）

1. 冻结可估计性度量：`K_eff = 1/(1−error)²`；三态阈值见 §5；
2. 对全部现存 IPV 产物（sigma01 时间序列、RQ009 特征矩阵/目标、RQ012B OnSite、
   RQ010B/RQ014 WOD 侧）逐行打标，产出 `estimability_ledger`；
3. **画像必须同时给出帧级与 case 级两套口径**（依据 §2.4b：两者结论差别巨大），
   并对每个下游产物标明其真实分析单位与相应的受损程度；
4. **回答"什么预测了帧级可估计性"**（依据 §2.4c：接近程度只解释一小部分）。
   候选预测子：观测窗长度、轨迹曲率/减速幅度、候选轨迹间的可分离度、路径类型、
   数据源与采样率。这是判定"可修 vs 固有识别极限"的关键证据；
5. 查清 §2.5 的 K>7 异常来源，必要时按 K 分组重算阈值；
6. **episode 级摘要规则**：沿用并扩展 RQ007-KC-C3 的可估计性加权，
   给出"仅可估计帧"与"可估计性加权"两种摘要的对照；
7. 交付：双口径可估计性画像报告、可估计性预测子分析、打标产物、异常裁定、摘要规则建议。

### Phase B — 估计器修复与影响评估

1. **B1 log 域**：`cal_traj_reliability` 改为 log-sum-exp（max 减法）。
   注：该修复在 RQ010B 的 WOD adapter 中已存在，但**未回流核心估计器**，
   InterHub/RQ009/RQ007 全线仍是概率空间版本；本阶段负责回流并统一。
2. **B2 显式弃权**：删除均匀兜底，改为返回 `status=NOT_ESTIMABLE` 且 `ipv=NaN`；
   调用方必须显式处理，禁止把弃权当作 0 参与任何聚合。
3. **B3 σ 语义复位**：log 域下 σ 只控制锐度而非数值悬崖；对 σ ∈ {0.05, 0.1, 0.2, 0.5}
   做敏感性，报告可估计率与 IPV 分布形态，**不以下游关联为选择准则**。
4. **B4 影响评估**：在冻结的子样本上比较修复前后的 IPV、`ipv_error`、
   以及 RQ009 M3 中心/区间。若 M3 需重训则另立计划，本阶段只做影响量化。
5. 交付：修复后的估计器 + 平价测试 + 前后对比报告 + D1/D2 定量拆分。

### Phase C — 既有阴性的可估计性条件重估

对 RQ010B（WOD 偏好效度）、RQ011B（OnSite 时刻监控）、RQ012B（偏离→危害）、
RQ003（NSFC 增量）四项已冻结阴性，在**冻结的可估计子样本**上重跑其原始预登记检验：

- 不修改任何原检验的估计量、统计单位或阈值；唯一变化是样本限定；
- 每项分别报告：可估计子样本的 n、效应量、与原结论的差异；
- **无论结果如何都不自动修改任何已冻结 decision.md**；修订须另走各 RQ 的
  scoped decision 流程。

## 5. 冻结定义（看任何重估结果之前）

```text
K_eff = 1 / (1 − ipv_error)^2          # ipv_error = 1 − sqrt(sum(w^2))
K     = 该行实际候选数（须显式记录，见 §2.5）

ESTIMABLE      : K_eff ≤ 4
WEAK           : 4 < K_eff < 0.93·K
NOT_ESTIMABLE  : K_eff ≥ 0.93·K        # K=7 时对应 error ≥ 0.61
```

主分析集 = `ESTIMABLE`。`WEAK` 只进敏感性。`NOT_ESTIMABLE` 永不进入任何数值聚合，
只计入弃权率。阈值 4 与 0.93·K 在本文件冻结，SHA 登记于计划校验和。

## 6. 验收标准

- **A 通过**：全部现存产物打标完成、K>7 异常有明确裁定、画像报告经独立复核；
- **B 通过**：log 域实现通过平价测试（在无下溢样本上与旧实现数值一致）、
  弃权路径有单元测试、D1/D2 拆分有定量结论；
- **C 通过**：四项重估各自产出诚实结论，且未触碰任何冻结 decision。

## 7. 边界与禁止事项

- 本 RQ **不**提出任何新的社会性行为学主张；它是**测量学**研究。
- 不得以重估结果反向调整可估计性阈值、σ 或候选网格。
- 不得在 Phase C 前修改任何已接受 claim；RQ007-KC-C2（"高指数 ≠ IPV 0"）
  与实测 `P(IPV=0 | error≥0.61)=73.8%` 的张力，登记为待核查项，
  由 RQ007 的知识层按其自身流程处理。
- 与 RQ014 的关系：RQ014 冻结 lane 不受影响；其唯一通过格的 42 个场景
  应在 Phase A 完成后补充可估计性画像，作为该结果的条件性说明。

## 8. 资源与执行

Phase A 主要是打标与统计，CPU 秒级至分钟级，本地即可；Phase B 涉及估计器重跑，
需 HPC（`zxc-rq015-*`）；Phase C 复用各 RQ 的既有脚本，只加样本限定。

## 9. 为什么这件事优先

四个已注册阴性（RQ003/RQ010B/RQ011B/RQ012B）都建立在一个未经检验的前提上：
IPV 是被测到的。实测显示超过一半的样本上它其实没被测到。在澄清这一点之前，
无论是继续追加阴性、还是基于 RQ014 的单格候选去做前瞻检验，
都可能是在一个系统性衰减的测量上做文章。

## 2. 【必须补进叙述】C3 的 22% 为什么纹丝不动 —— 这是本轮最有价值的发现

F1 报出扣除下溢前后严格变号率 `0.234483 → 0.234483`，分子分母都是 `2943/12551`。
我最初判定这是"消融没作用到变号统计上"的缺陷，独立重算后**推翻了自己的判断**：

```
baseline signable 集合与 exclude signable 集合  ——  完全相同（对称差 = 0）
baseline flip 集合与 exclude flip 集合          ——  完全相同（对称差 = 0）
```

成因是结构性的，不是巧合：

- RQ007 的**严格变号**规则要求两个均值都 ≠ 0，因此把 663 个"某一侧均值恰为 0.0"的
  case-agent 排除在分母之外；
- 这 663 个里有 **628 个（94.7%）的 interaction-active 帧全部是下溢帧**——
  正是"下溢把 ipv 钉死为精确 0.0"造成的；
- 也就是说，**下溢污染的行早就被 RQ007 自己的严格变号规则挡在分母外了**。
  消融把它们删掉，删的是本来就没参与统计的行，分母自然不动。

**这条对 PI 的意义**：C3 的 22% 不是"扛住了检验"，而是**在这个统计量上结构性免疫**——
strict-sign 规则恰好等价于一个下溢过滤器。这比"扛得住"三个字信息量大得多，
建议 PI 在读结论表时以此为准。同时注意反面：正因为如此，
**这 628 个 case-agent 在 RQ007 的 C3 里是被静默丢弃的**，而它们占 active 有效 case-agent 的
628/13,214 = **4.75%**。C3 原文没有声明这个丢弃。

另一半证据独立支持"C3 非伪影"：`mean|Δ|` 扣除下溢后 **0.2647 → 0.2919，升高 10.3%**，
方向与"伪影说"相反（下溢行原本在稀释这个差）。替代法（把下溢 ipv 换成同 case-agent 非下溢均值）
给 0.2446 / 20.7%，两种处理都没有把 C3 打塌。

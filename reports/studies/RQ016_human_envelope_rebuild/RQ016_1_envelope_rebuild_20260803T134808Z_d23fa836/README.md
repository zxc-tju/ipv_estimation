# RQ016-1：用只过门的样本重建人类 envelope（执行记录）

执行日期：2026-08-03｜基线提交：`d23fa836`｜执行方：单个 codex agent（A1）｜监督方：Claude

## 这一轮在整个研究里的位置

最终目标是在线验证：判断一辆自动驾驶车表现出的社会交互倾向像不像人。判定由两道
串联的弃权机制构成——机制一判断某一帧的 IPV（Interaction Preference Value，
表示交互倾向的标量）数值能否估出，估不出直接弃权、不进机制二；机制二判断当前场景
收集到的人类样本是否足以判断该车是否偏离。

RQ015 完成并冻结了机制一。**本轮解决的是机制二所依赖的人类参照分布（envelope）
建在含伪零样本上的问题**：旧估计器在数值下溢时退回七候选等权，而候选网格对称，
必然写出 IPV 恰为 0，使「没估出来」与「该个体 IPV 恰为中性」在数据里不可区分。

## 做了什么

在 K2 台账覆盖的 `development + guard` 域内，用同一套方法跑两臂，唯一变量是样本口径：

- **A 臂**（域内基线）：保留全部覆盖行，含伪零，即现状
- **B 臂**（处理组）：只保留机制一通过（`status == OK`）的行

context 分箱沿用 RQ009 已接受的 M2 定义（22 个数值 + 7 个类别变量，
`source_dataset` 不作预测变量）。

## 主要结果

90% 名义层：coverage 0.898832 → 0.902689，平均区间宽度 1.016189 → 1.300967（**+28.02%**）。
两道门串联的合并弃权率 **32.0583%（284,964/888,892）**，其中机制一 28.4932%
（253,274/888,892）、机制二 3.5651%（31,690/888,892）。

变宽的机制由监督方独立证实：目标的四分位距从 0.0493 变为 0.2017（约 4.09 倍）。
即旧 envelope 偏窄，是因为约五分之一的「人类样本」是精确的 0，其中约一半是计算失败
被写成 0 的。

### E15 — Abstract adjective "narrow" vs the absolute width
- **Issue.** The abstract promises "a narrow, calibrated, auditable runtime monitor". D-M8: the
  relative sharpening (21/20/8%) is real, but the conditioned 90% width averages 1.87 rad — 79% of
  the 2.36-rad admissible span (5th–95th percentiles 1.35–2.28) — "so the instrument flags only
  near-extreme preferences; 'narrow' is not an accurate description and the honest
  relative-vs-absolute contrast appears only in a caption parenthesis." The numbers verify against
  frozen evidence (RQ021 key_numbers; printed in the Fig-4 caption). Plan item U04 already surfaces
  the absolute width in §2.3 with a positive reading (a wide reference means a flag marks a clear
  departure); the remaining decision is the abstract word itself, which is PI territory.
- **Options.**
  - (a) Keep "narrow" and rely on U04 + the response letter (argument: "narrow" is explicitly
    comparative in context — the sentence contrasts the conditioned range with the global range that
    "can never flag a moment"). Risk: D-M8 shows a careful referee reads it absolutely; the same
    objection returns.
  - (b) ★ Replace with the comparative at the next abstract-touching pass: "gives a sharper,
    calibrated, auditable runtime monitor" (or "...a calibrated, auditable runtime monitor, sharper
    than any global range"). Frozen-backed (21/20/8%), unimpeachable, zero information loss; costs
    one word.
  - (c) Drop the adjective entirely ("a calibrated, auditable runtime monitor"). Safe but forfeits
    the sharpening headline in the abstract.
- **Consequence.** (a) invites a repeat of D-M8 at the journal; (b) removes the attack surface while
  keeping the claim; (c) under-sells a real, frozen advantage. (b) should be executed together with
  the E2 five-site abstract pass to avoid editing `\targetnum`-adjacent abstract prose twice.
- **Reviews.** D-M8, D-P6; adjacent: B-M2/C-M2's "calibrated" qualifier demands (already served by
  the printed marginal-coverage boundary — no abstract change recommended for "calibrated").
- **Recommendation.** (b), bundled into the E2 swap-time wording pass.

1. 系统定位

系统用于收集前瞻性人类主观判断，验证 conditional social atypicality → human dispreference。IPV 和人类参考区间由上游冻结流程生成；网页只读取匿名刺激清单并采集评价。

参与者页面不接收 Human/AV 来源、区间内外判定、偏离方向、偏离幅度、系统编号或驾驶员编号。

2. 单次实验流程

1创建匿名会话
2知情同意
3持照筛查
4背景信息
5说明与练习
6Pairwise
7休息
8Single-clip
9事后问卷与完成码

Pairwise trial

顺序播放 A、B 两段同场景视频，允许一次完整重播；收集 A / B / 无明显偏好和 1–5 分置信度。两段视频必须属于同一 matched_set_id。

Single-clip trial

收集 7 个独立的 1–7 分评价：可接受性、互动舒适度、可预测性、对另一方的调整负担、感知不安全、过度激进、过度谨慎。可接受性、安全感和互动负担不会被合并。

3. 数据与审计

层级主要内容
Participant / Session匿名编号、同意版本、筛查结果、背景信息、开始/结束与完成状态
Trial顺序、类型、刺激 ID、开始/提交时间、播放完成、重播次数、响应时长
Pairwise response原始 A/B/无偏好、映射后的首选刺激、置信度
Single response七项 1–7 分评价和可选开放理由
Event log页面可见性、播放/暂停/结束、视频错误、重播与页面卸载
Hidden manifest来源、verdict、side、偏离幅度与质量门，仅管理员导出可见

数据保存在 SQLite，启用 WAL；管理员可导出 participants、sessions、trials、pairwise、single、events 六类 CSV，以及包含冻结配置和刺激清单的完整 JSON。

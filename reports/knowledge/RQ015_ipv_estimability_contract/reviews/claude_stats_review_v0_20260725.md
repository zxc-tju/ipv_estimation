## 3. BLOCKING findings

### B1 — §2.5「K>7 异常 = K≥9 网格混入」的机制归因**经实测证伪**；实为未估计哨兵，且 §5 公式在该处除零

- **严重度**：CRITICAL（同时命中职责 2 与职责 3）
- **证据**：
  - 复算：`ipv_error > 1−1/√7` 的 305,824 个值**无一例外恰等于 1.0**。任何 K 的归一化权重向量
    都满足 √Σw² ≥ 1/√K > 0 ⇒ `error = 1−√Σw² < 1`。**`error=1.0` 在数学上不可能来自任何候选网格**，
    因此「混入 K≥9 的行」的解释被排除。
  - 源码：`src/sociality_estimation/core/ipv_estimation.py:251-252`
    ```python
    ipv_values = np.zeros((steps, 2), dtype=float)
    ipv_errors = np.ones((steps, 2), dtype=float)
    ```
    这两行是**数组初始化**；`pipelines/interhub/process_interhub.py:48` `MIN_OBSERVATION = 4`，
    前 4 帧不进入估计循环，于是保留初始值 `(ipv=0.0, error=1.0)`。
  - 数量核对：`38,228 cases × 4 frames × 2 agents = 305,824`，与实测**精确相等**。
  - 位置核对：这 305,824 个值的 `frame_index` 100% ∈ {0,1,2,3}（max=3），IPV 100% 为 0。
  - 传播路径：`process_interhub.py:604-609` 的 `compute_valid_ipv_summary` **已按 `min_observation` 裁掉**
    这些行，因此 case_summary 干净；但 `write_timeseries`（同文件 855-885）写出**全量数组**，
    所以哨兵只污染帧级时间序列产物——恰恰是 RQ009 M3 锚点、RQ014 逐 tau 读数所用的那一层。
- **为什么这是阻断而不是笔误**：
  1. §5 冻结的 `K_eff = 1/(1−ipv_error)²` 在 `error=1` 处**除零 → +inf**，对 4.14% 的值未定义。
     计划把它归入 `NOT_ESTIMABLE`（K_eff≥0.93K）在数值上"侥幸正确"，但理由完全错误。
  2. 计划的 D1/D2 二分**遗漏了第三类机制 D0「从未尝试估计」**。D0 行不是数值下溢（D1），
     log-sum-exp 改造对它们**完全无效**；Phase B 之后它们必然残留，而 §2.4e 明文规定
     「残留部分即可归因于 D2（固有不可辨识）」（计划 L157）。于是 H2 的 D1/D2 定量拆分
     **会把 305,824 个纯粹的实现 artefact 记为"固有不可辨识"**，直接污染 RQ015 的核心交付物。
  3. §2.1「零值行中 92% 的 error≥0.61」等描述性统计包含这 9.47% 的 D0 行；
     §2.4b 的 case 级"可估计比例均值 23.37%"分母也含 4 帧哨兵。
- **最小修复要求**：
  1. 改写 §2.5：把"K>7 异常"重新裁定为 `frame_index < MIN_OBSERVATION` 的初始化哨兵，
     引用 `ipv_estimation.py:251-252` 与 `process_interhub.py:48`，并记录 305,824 的精确恒等式；
     不需要"按 K 分组重算阈值"（实测已证明 K≡7，见 M2）。
  2. 在 §5 三态之外新增 **`NOT_ATTEMPTED` (D0)** 状态，判定式为 `frame_index < MIN_OBSERVATION`
     或 `ipv_error ≥ 1−1e-12`；显式规定 `K_eff` 在该状态下**不计算**（避免除零）。
  3. §3-H2 改为三分（D0/D1/D2），并明文规定 D0 行在 D1/D2 比例计算中**必须先剔除**。
  4. Phase A 打标产物必须携带 `frame_index`、`MIN_OBSERVATION` 与 `K`，否则下游无法复现该剔除。

### B2 — Phase B 的 log 域改造在 σ=0.1 下退化为硬 argmax，使 H2 不可证伪、并使 §5 冻结阈值在修复后失效

- **严重度**：CRITICAL（职责 3 与职责 5）
- **证据**：
  - 现有 log 域实现就在仓库里：`scripts/rq014/wod_ipv_adapter.py:87`
    `shifted[finite] = mean_loglike[finite] - np.max(mean_loglike[finite])`，
    其中 `mean_loglike[idx] = mean(-(rel_dis**2) / (2*sigma**2))`（同文件 L80）。
    （附带确认：计划 §Phase B1「该修复在 RQ010B 的 WOD adapter 中已存在，但未回流核心估计器」**属实**——
    `logsumexp` 在非 venv 代码中零命中，唯一 log 域实现即上述手写 max 减法。）
  - `src/sociality_estimation/core/agent.py:95` `sigma = 0.1`（米）。修复后两候选的权重比为
    `exp((d₂²−d₁²)/(2σ²)) = exp((d₂²−d₁²)/0.02)`。在 RMS 偏差 3 m 量级上，两候选相差
    **1 cm** 即给出 e³≈20 的权重比；相差 **10 cm** 给出 e³⁰≈10¹³。
  - 换言之：**只要七条候选轨迹彼此不是逐点相同到 ~1 cm 以内，log 域必然给出近 one-hot 权重**
    ⇒ `ipv_error ≈ 0` ⇒ `K_eff ≈ 1` ⇒ 按 §5 全部落入 `ESTIMABLE`。
  - 佐证：现有 InterHub 产物中 `err<1e-9` 的 one-hot 行已有 128,028 个，其中 **90.87% 压在网格边界**——
    这正是"似然单调、被 argmax 钉死"的指纹。
- **后果**：
  1. **H2 不可证伪**。「改 log 域后 D1 类零值大幅减少」在 σ=0.1 下是**定义上必然成立**的，
     无论 D1 是否真实存在。§2.4e 声称"Phase B 对 D1 类零值的消除预期是高的；残留部分即可归因于 D2"，
     但按上述推导残留几乎为零（除 D0 外），于是 D2 将被测成 ≈0——这是算法的自证，不是科学结论。
  2. **§5 冻结的阈值在修复后无判别力**。阈值 `K_eff≤4` / `≥0.93K` 是在**修复前**的分布上冻结的；
     修复后 K_eff 分布塌到 1 附近，`ESTIMABLE` 覆盖率 →~100%，"可估计性契约"沦为恒真谓词。
     计划 §5 声称阈值一次冻结贯穿全项目，与 Phase B 会改变被度量对象的事实**直接冲突**。
  3. B3 的 σ 敏感性网格 `{0.05, 0.1, 0.2, 0.5}` 全部**远低于轨迹模型自身的误差量级**
     （RQ010B 记录的 tracker 误差 ≈1.2 m；RQ010B 亦记录 4 Hz vs 10 Hz 的 per-candidate IPV
     Spearman 仅 0.29–0.31，说明估计量本身对 ~0.1 m 级扰动极不稳定）。在 σ ≪ 模型误差的区间做敏感性，
     只是在比较不同程度的 argmax。
- **最小修复要求**：
  1. **先做零成本预演**：在**已有的** RQ010B/RQ014 WOD log 域产物上，直接报告 `ipv_error` /
     `K_eff` 的经验分布与 one-hot 率。若如预测般塌到 K_eff≈1，Phase B 的设计必须先改再执行。
  2. σ 敏感性网格必须**上探到与轨迹模型误差同量级或更高**（至少加入 0.5 / 1.0 / 2.0 m），
     并把 σ 明确重定义为"轨迹似然的观测噪声尺度"而非自由旋钮；给出选择 σ 的**外生**准则
     （例如与候选轨迹间平均分离度或与观测/重建误差挂钩），而不是"看可估计率好看"。
  3. H2 改写为可证伪形式，例如：「在 D0 剔除后，log 域下 `K_eff` 中位数随 σ 的变化曲线，
     在 σ 达到 X 时仍有 ≥Y% 的行保持 K_eff ≥ Z」——并预登记 X/Y/Z。
  4. §5 明确承认：修复会改变被度量的量，因此需要**两套阈值**（pre-fix 冻结用于 Phase A 画像，
     post-fix 阈值在 Phase B 的**分布特征**上重新冻结、且必须在任何 Phase C 结果之前冻结）。
     现文本"一次冻结贯穿全项目"必须撤回，否则要么阈值失效、要么留下事后调参的空间。

### B3 — `ESTIMABLE` 主分析集被**候选网格边界截断**主导；K_eff 是集中度而非精度，无法识别这一污染

- **严重度**：CRITICAL（职责 2）
- **证据**（本复审实测，已剔除 D0 哨兵）：
  - `err ≤ 0.3`（"强可估计"，n=925,509）中，最近格点 `|k|=3` 的占 **71.01%**；
    `|IPV| ≥ 3π/8`（数学上要求权重**全部**压在端点）的占 **12.95%**。
  - `err < 1e-9` 的 one-hot 行（n=128,028）中，**90.87% 压在 ±3π/8 端点**，只有 1.33% 在 0。
  - `err ≤ 0.5` 全集（n=1,712,634）中 7.00% 压在端点。
  - 网格：`src/sociality_estimation/core/agent.py:63`
    `virtual_agent_IPV_range = np.array([-3,-2,-1,0,1,2,3]) * math.pi / 8`（K=7，步长 π/8=0.3927 rad，
    全域 2.356 rad）。
- **为什么这毁掉主分析集**：端点堆积意味着似然在网格上**单调**，真值落在 `[-3π/8, 3π/8]` 之外。
  这是**截断/删失**，不是识别。但 `K_eff` 只看 Σw²，把"完美删失"读成"完美可估计"——
  于是 §5 的 `ESTIMABLE` 定义会把最严重的模型设定失配样本优先纳入主分析集。
- **K_eff 的正式评价（职责 2 逐条回答）**：
  - **变换本身正确**。令 S=Σw²，则 `error = 1−√S` ⇒ `S=(1−error)²` ⇒ `K_eff = 1/S`。
    这**恰好**是 inverse participation ratio / inverse Simpson 指数 / Hill number of order 2，
    值域 [1, K]，均匀时 =K，one-hot 时 =1。计划这一步没有代数错误。
  - **但它是集中度，不是精度**。它对网格几何完全不敏感：
    (a) 权重集中在**相邻**格点（真正的窄后验）与集中在 **±3π/8 两端**（双峰、点估计因对称抵消恰为 0）
    给出**同一个 K_eff=2**；(b) 端点删失（B3 主体）与内点确信同样给出 K_eff≈1。
    实测佐证：`err≤0.3` 的子集中仍有 21,147 个值（2.285%）IPV≈0——集中度高但点估计落在 0，
    与"高指数 ≠ IPV 0"的镜像情形（RQ007-KC-C2）互为对照，说明单靠 K_eff 无法区分这些机制。
  - **阈值 4 与 0.93 无原则性依据**。`K_eff ≤ 4` 在 K=7 下意味着后验有效散布在 7 个格点中的 4 个，
    约 1.57 rad / 2.36 rad ≈ **全域的 66%**，仍被称为"有实质辨识力"并作为**主分析集**。
    计划 §2.2 把 `error≤0.5` 注为"有实质辨识力"是一个未加论证的断言。0.93 同理（见 M2）。
- **最小修复要求**：
  1. Phase A **必须重算并落盘权重向量 w**（现有产物只有均值与集中度，信息不可逆）；
     没有 w 就无法把删失、双峰、窄后验分开，"可估计性契约"的科学内容无法成立。
  2. 主分析集判据必须**同时含位置/精度条件**，最低限度：
     `ESTIMABLE := K_eff ≤ τ AND argmax(w) ∉ {±3}`（众数非端点），
     并另设 `BOUNDARY_CENSORED` 状态单列统计，永不与内点估计混入同一聚合。
     建议把主判据换成网格上的后验标准差（`sd = √(Σwᵢ(θᵢ−θ̄)²)`），它同时对集中度与几何敏感，
     并且可以用 rad 给出可解释的阈值。
  3. τ（无论 4 还是别的）必须给出依据（例如：使后验 sd ≤ 半个格距 π/16 的等价 K_eff），
     或明文登记为"约定性、仅用于分层、不承载'已测到'的语义"。
  4. Phase A 交付物须报告**每个下游产物的端点命中率**；`RQ014` 唯一通过格的 42 个场景
     必须单独报告端点命中率（§7 已要求补画像，此项应写死为必检指标）。

### B5 — Phase C 的"唯一变化是样本限定"不成立：可估计性与结果侧变量相关，且四次重估无多重性/检验力控制

- **严重度**：MAJOR / 提升为 BLOCKING（职责 4）
- **证据**：
  - **选择与结果相关（直接实测）**：case 级 PET 均值，≥5 可估计的 case = **1.4117**，
    <5 的 = **1.5299**；`corr(case 内可估计比例, PET) = −0.0934`（n=38,228）。
    intensity 的组均值差高达 265,497 vs 13,709（重尾，corr 仅 +0.014，均值受离群主导，
    但组间差异本身说明分层不随机）。
  - RQ007 decision.md L30 的边界明文把 **PET / intensity / order / priority / outcome 列为结果侧字段**
    （"No map/lane, observed PET, intensity, order, priority, or outcome fields used"）。
    因此"按可估计性限定样本"**就是在结果侧变量上做选择**，不是中性的。
  - **语料构成剧变**：ESTIMABLE 子样本中 nuplan 从 26.4% 降到 **11.8%**（腰斩），
    waymo 从 53.0% 升到 **62.7%**。四项被重估的阴性各自绑定不同数据源与不同的域外泛化论证，
    构成移位会直接改变可比性。
  - **检验力**：RQ010B 的 n 上限为 75–98（decision.md L45、L52 记明「underpowered for |ρ| < ~0.28」）。
    在其上再施加可估计性限定，n 只会更小。计划 §4-Phase C 只要求"报告 n 与效应量"，
    **没有预登记最小 n、没有检验力下限、没有停止规则**。
  - **多重性与分叉**：4 个 RQ × {ESTIMABLE, WEAK} × {σ 敏感性至少 4 档} 构成一个可观的检验族，
    §5 只把 `WEAK` 写为"只进敏感性"，未规定敏感性结果**不可晋升为主结论**，也无族错误率控制。
  - **§3 的防线不足**：H3 声称"两种结果都要如实登记"、§7 声称"不得以重估结果反向调整阈值"。
    如实登记是**报告规范**，不是**统计控制**；它无法阻止选择效应制造的假阳性，也无法阻止
    在四个族成员中挑出唯一显著的那个来讲故事。§2.4e/§2.4c 已展示计划作者倾向于用
    "剂量-反应""不是接近程度"这类叙事推进，防线需要比自律更硬。
- **最小修复要求**（缺一不可）：
  1. **把"选择"换成"调整"作为主分析**：主设定应为在**全样本**上把可估计性（K_eff 或后验 sd）
     作为**预登记协变量/交互项**（这正是 RQ014 诊断 §5.2 的建议），
     可估计子样本重估降级为**次要/敏感性**分析。这从根上消解选择效应。
  2. 若坚持子样本重估：预登记**单一**主子样本定义（仅 ESTIMABLE，且已按 B3 排除端点删失），
     预登记每项的**最小 n 与最小可检测效应**，n 不足则登记为 `UNDERPOWERED_NOT_RUN`，
     不得报告点估计。
  3. 预登记族错误率控制（4 项主检验的 Holm 或 max-statistic 置换，与 RQ010B 已用的
     max-stat permutation 保持一致）。
  4. 预登记**选择效应诊断**为强制交付物：每项报告可估计 vs 不可估计子样本在结果侧协变量
     （PET / intensity / path_category / 数据源构成）上的平衡表；不平衡时必须给出加权或
     倾向性调整结果作为主报告的一部分。
  5. 明文写死：`WEAK`、σ 变体、post-fix 阈值下的任何结果**永不可晋升为主结论**。

## 4. MAJOR findings

### M1 — §2.1「32.4% 精确等于 1−1/√7」复算不成立（实为 9.88%），D1 兜底分支规模被高估约 3.3 倍

- **证据**：计划 L35-36。我在 1e-9 容差下得 319,246 = 零值的 **9.88%**；要达到 32.4% 需约 2e-5 容差
  （1e-6→22.11%，1e-4→57.15%）。
- **为什么重要**：`error` 精确等于 `1−1/√7` 是 `agent.py:1136-1139` 的 `else: weight = np.ones(K)/K`
  兜底分支的**唯一指纹**；仅仅"接近"均匀是另一种机制（权重近乎相等但 `sum(var)>0`，
  即 D2 式的候选不可分辨），二者的修复方案完全不同。把后者算进前者会系统性高估 D1、低估 D2，
  从而在 Phase B 之前就为 H2 预设了答案。
- **最小修复**：§2.1 改为报告"精确兜底率 9.88%（容差 1e-9）"，并单列"近均匀（1e-9 < |Δ| ≤ 1e-4）
  的 47.3 个百分点"作为**不同机制**；对应地把 §2.4e 的 D1 强度断言下调并重新论证。

### M2 — §5 内部阈值不自洽，且 `0.93·K` 依赖一个产物中不存在的量 K

- **证据**：§5 定义 `NOT_ESTIMABLE : K_eff ≥ 0.93·K`，K=7 时等价于 `error ≥ 0.6080691`；
  计划括注"K=7 时对应 error ≥ 0.61"，但 0.61 对应的是 `K_eff ≥ 6.5746 = 0.9392·K`。
  实测两者相差 **52,776 个值（0.714% of N）**：0.93K 规则给 55.2568%，0.61 给 54.5429%。
  全文（§2.2、§2.3、§3-H1）一律用 0.61，§5 冻结的却是 0.93K。**冻结文件内部有两个不同阈值。**
- **另**：§5 要求 `K = 该行实际候选数（须显式记录，见 §2.5）`，而 §2.5 自承产物中没有 K。
  本复审已证明 K ≡ 7（唯一超出 `1−1/√7` 的取值恰为 D0 哨兵 1.0，见 B1），所以"按 K 分组"
  这一 Phase A 工作项应被删除；但**跨产物**仍不能假定 K=7（见 M3）。
- **最小修复**：二选一并全文统一；在 §5 直接写出 K=7 下的数值阈值（如 `error ≥ 0.6080691`）
  以消除歧义；把"K 须显式记录"的要求保留给 **Phase B 之后的新产物与非 InterHub 产物**。

### M3 — §5 契约跨 K / 跨网格不可比，而 Phase C 恰好要跨三个语料使用它

- **证据**：`agent.py:63-64` 存在两个网格：
  `virtual_agent_IPV_range`（K=7，等距 [-3..3]·π/8）与
  `realtime_agent_IPV_range`（**K=5，非等距** [-3,-1,0,1,3]·π/8）。
  在 K=5 下，`ESTIMABLE: K_eff≤4` 意味"5 选 4"；`NOT_ESTIMABLE: K_eff ≥ 0.93·5 = 4.65`
  对应 `error ≥ 0.5363`，于是 **WEAK 带只剩 error ∈ (0.5, 0.5363)，宽 0.036**——三态契约退化为二态。
  非等距网格还会让 K_eff 与"角度分辨率"的关系彻底断裂。
- Phase C 要在 RQ010B（WOD）、RQ011B/RQ012B（OnSite）、RQ003（NSFC）四个语料上套用同一契约。
  我已确认 WOD 侧 `scripts/rq014/wod_ipv_adapter.py:121` 与 `build_wod_m3_anchors.py:510,750`
  用 `solver_mode="exact"`（K=7），但 OnSite / RQ003 侧的网格、σ、窗口未在本复审范围内逐一核实。
- **最小修复**：Phase A 增加一项前置交付物——**逐产物的估计器配置清单**（K、网格取值、σ、
  `history_window`、`min_observation`、是否 log 域）；契约必须以**网格无关**的量表述
  （建议后验 sd，单位 rad），或对每个 K 分别冻结阈值并论证可比性。

### M4 — §2.4c 的结论用份额加权掩盖了条件效应，与冻结的 RQ007-KC-C1 实质冲突，违反 §7 的自我约束

- **证据**：计划 L125-127 断言「可估计性**不是**简单的'离得近才测得到'」，理由是 <5 m 档只占 3.8% 帧。
  但我复算确认的条件效应本身很大：<5 m 档 `err≤0.5` = **44.50%**，其余各档 21.2–23.9%——
  **接近一倍**。「只占 3.8% 的帧」是**边际份额**论证，不能否定**条件**关系；
  RQ007-KC-C1（ACCEPTED）说的正是条件关系：「Most of the gap (≈ −0.096) is spatial proximity」。
- 计划 §7 明文「本 RQ **不**提出任何新的社会性行为学主张」，但 §2.4c 的措辞与 §4-Phase A-4
  （"决定了不可估计是可修的采样/实现问题，还是 IPV 模型在该类轨迹上的固有识别极限"）
  已经在**预判**一个与冻结 claim 相反方向的结论。L128-129 的脚注承认了张力但没有解决它。
- **最小修复**：把 §2.4c 的结论重述为条件形式（"接近程度是最强的单一已知预测子，
  但 5 m 以外仍有约 22% 的可估计帧，说明存在其他未识别的驱动因素"），删除
  「不是简单的离得近才测得到」这类与 RQ007-KC-C1 对立的措辞；或者按 §7 自己的规则，
  把它登记为待核查项交给 RQ007 知识层，不在 RQ015 计划正文中下判断。

### M5 — 预登记的可证伪性与"看结果再调"的口子（职责 5 综合）

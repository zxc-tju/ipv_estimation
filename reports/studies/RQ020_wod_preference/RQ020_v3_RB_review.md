## 第一阶段：未见 RQ020 任务书的独立推导

### 阶段边界声明

本节在打开 `.codex-fleet/rq020-wod-preference/board/RQ020_kickoff_v3.md` 之前完成并写定。形成以下判断时，没有读取 `.codex-fleet/rq020-wod-preference/`、`reports/studies/RQ020_wod_preference/` 或任何其他 RQ020 复审目录。本阶段只使用 RQ010、RQ012、RQ014、RQ016C 的允许记录；遇到评分相关字段时不读取逐条内容。

### 1. RQ014 找到了什么，以及不能把它说成什么

RQ014 不是一个普通的前瞻假设检验，而是已知目标方向下的规格恢复：冻结合同明确把目标定义为从同一批数据中找回一个能复现记忆中负向关系的计算 recipe，并明确 p 值不控制恢复判定（`reports/plans/RQ014_recovery_lane_v3.json:6-21`）。其搜索空间是 320 个 predictor cells，每格又产生 RWS、PSP、PPR 三种关联，共 960 个关联行（同文件 `:227-232` 及 `:588-600`）。

实际结果只有一个通过恢复门的次要项：`R04N / CH-W25 / H20 / NMD_MEAN / RWS`，`r=-0.384, n=42`；预先指定的主偏离量 NEX 没有通过项。同 recipe 的 NEX 方向也为负，但只有 `n=37`，没有越过 `n>=40` 的恢复门。R10L 分支因上游整支终结缺陷不能作科学阴性结论（`reports/knowledge/RQ014_wod_e2e_rating_recovery/README.md:50-68`；`reviews/codex_review.md:72-104`；`reviews/claude_results_review_20260725.md:73-99`）。

这个正面项的效力边界有五层：

1. 它只说明在 42 个有信息场景内，各场景三个候选的偏离排序与人类偏好排序呈负向一致；不是对 479 个场景绝对评分的预测。
2. 它来自已知负方向、同一批数据上的相关配置搜索；320 格共享场景、转换和大量上游计算，不能当作 320 次独立重复。
3. fold、逐场景删除和逐场景簇删除都从同一个已选支持集重算，只证明该小支持内没有明显单点或单簇翻转，不是独立复制。
4. RQ014 使用的 RQ009 M3 在 WOD 上是明示的支持外外推，历史试点为 `0/228` 通过支持门；合同仍消费 pre-OOD-mask 输出，只是为了恢复旧规格（`reports/plans/RQ014_recovery_lane_v3.json:36-53`）。
5. selected-recipe 冻结和独立 clean replay 未完成；即使完成，也只能证明同一 recipe 在同一数据上可计算复现，不能消除最初选择，也不能建立跨数据外部效度。

因此，RQ014 找到的是一个**有界、次要、选择后的场景内候选排序信号**，不是已确认的人类偏好效度，更不是 M3 已迁移到 WOD。

### 2. 哪些可复用，哪些复用即继承选择效应

可以直接复用的是与结果方向无关的工程和审计合同：

- score-stripped 特征阶段与单次受控评分连接的物理隔离；
- 三候选 segment 作为依赖簇、候选源顺序不得解释为偏好顺序；
- 候选、对手和历史轨迹的严格 ID/时间对齐与哈希绑定；
- 只在观测位置支持内插值、按精确闭区间切窗、再在窗内重建状态；
- 每个 cell 必须落到一个终态，保留全部 attrition、分母、支持 ID 和失败原因；
- 评分解锁前冻结模型字节、特征 bank、支持门、四格家族、主次顺序和停止规则；
- RWS 的“先在场景内比较三个候选、再对场景等权汇总”语义，前提是研究问题仍是同场景候选排序。

不能作为全新确认性选择直接复用的是 `R04N / CH-W25 / H20 / terminal estimator row` 以及与之绑定的 `NMD_MEAN / RWS` 赢家链。即便每一项都能事后给出合理的测量学解释，它们作为组合已经由同一批 479 个场景的评分从 320 格中选出。把 envelope 换成新版纯人类参照只改变 predictor 的一部分；候选、场景、响应和被选 recipe 仍来自原选择过程。因此新一轮普通 p 值和普通置信区间仍带选择后问题。

补救有三级，效力不同：

1. **真正补救**：在没有参与 RQ014 搜索的新评分样本上锁定该 recipe 后检验，或在另一个具有同类三候选人类偏好的数据集上检验。这才把 recipe 选择与检验样本分开。
2. **同数据集上的有限补救**：若只能用原 479 场景，必须把本轮明示为 post-selection sensitivity；若仍要给错误率，则置换时必须重演会影响当前选择的完整流程，至少包含原 320-cell 选择和本轮四格，而不是只置换冻结后的四格。它能标定完整选择管线在全局零假设下产生“赢家”的频率，但仍不是新数据确认。
3. **不能补救的做法**：clean replay、换实现、再切一次同一 479、或只在四格上做 Bonferroni。它们分别解决计算复现、实现错误或局部多重比较，不会倒转已经用全体评分选 recipe 的事实。

### 3. 换成更新的纯人类 envelope 后，我会怎样设计

研究问题应冻结为：在同一 WOD-E2E 场景的三个候选中，候选未来所表达的 IPV 相对**纯人类参照分布**偏离越大，是否对应更低的人类偏好；分析单位是场景，三个候选是场景内重复观测，结论仅是关联。

设计顺序如下：

1. **先证明参照适用于 WOD 查询。** RQ016C 的人类池口径可复用：只纳入机制一状态为 OK 的 `HV;HV` 行，并移除 `agent_type_pair`、`av_included`、`vehicle_type_list`，因为自动驾驶身份是被检验对象而不是情境（`reports/knowledge/RQ016C_human_only_envelope/README.md:17-27`）。但 RQ016C 产物是为 OnSite 构建且没有 WOD 同源迁移证据（同文件 `:45-51`），所以不能因“纯人类”三个字直接视为 WOD 有效。评分解锁前必须验证 WOD 的类别词表覆盖、22 项数值特征完整性、分格覆盖、各距离特征的支持分布，以及真实 WOD score-stripped 行能完整打分。
2. **冻结 envelope 与查询合同。** 模型、训练/校准样本口径、特征顺序、分格键、80/90/95 层、支持距离阈值和预处理全部按字节冻结；用独立的人类校准集验证名义覆盖率与区间宽度健康。任何未知类别、非有限边界、`M-L<=0` 或 `U-M<=0` 都必须终态化，不能用小常数静默修补。
3. **候选 materialization 保持评分盲。** 三候选使用同一历史、同一观测对手和同一 reference 构造；只允许候选未来不同。先按 scene×candidate×anchor 输出 IPV、区间、中心、支持状态与 QA，再冻结 bank。候选哈希必须与最终连接表逐一匹配。
4. **四格在连接前一次性冻结。** 家族为 `NEX/NMD × 支持门开/关`。支持门开表示只有三个候选均位于参照适用域的场景才能进入场景内比较；不能留下两候选再改变问题。支持门关保留 pre-OOD-mask 外推，但只能作为敏感性。
5. **主统计量仍可用 RWS。** 它与“三候选中偏离排序是否对应偏好排序”直接匹配，且场景等权。必须同时报告离散取值分布、并列比例、场景数、候选数、场景簇数、效应量、簇级不确定性和完整 attrition。不能用 pooled 候选行把 3n 当作独立样本数。
6. **先定最小有意义效应和停止门。** 若主格冻结后不能为预先指定的最小效应提供足够场景，不连接评分；或者只做有界描述并显式标为低功效，禁止把零结果写成“无关联”。

### 4. 偏离量：越界应为主，到中心距离应为次

我的主次顺序是：

1. **NEX + 支持门开**：主格。
2. **NMD + 支持门开**：关键次格。
3. **NEX + 支持门关**：支持外敏感性。
4. **NMD + 支持门关**：最低解释力的支持外敏感性。

理由是研究层级写的是“人类不认可”。NEX 在纯人类 envelope 内为 0，只在越过人类参照边界后增加，和“超出参照范围”这一构念最直接；NMD 则对区间内的中心位移也赋值，回答的是“离典型中心多远”，不能自动等同于人类不认可。NMD 通常并列更少、功效更高，但这不是把它升为主格的理由；RQ014 正是 NEX 信息场景少、NMD 次要项存活，事后换主终点会重复旧问题。

NEX 的代价是大量区间内 0 和场景内并列，实际有信息场景可能很少。因此必须在评分盲阶段报告 NEX 三候选向量的常数比例和可进入 RWS 的场景数。若它过不了预先的功效门，应停止主检验，不得用 NMD 的较好数值表现补位。NMD 的价值是判断偏好是否对人类分布内部的“非典型程度”也呈梯度关系，并诊断 NEX 的硬阈值是否损失过多信息。

### 5. 支持门应开；关门格的代价与限界

主格必须执行支持门。参照模型只有在与人类训练数据足够相近的情境中，其中心和区间才有“人类分布”的含义。RQ016C 在真实 OnSite 行上的支持门通过率只有 `21,936/67,861=32.3249%`，并且不同几何×优先权格从 `47.03%` 到 `0.00%`（`reports/knowledge/RQ016C_human_only_envelope/README.md:35-43`）；这说明支持不是装饰性 QA，而会决定可解释样本。

开门的代价是分母下降、场景构成改变，并可能选择出轨迹更平滑、跟踪更稳或更接近训练域的场景。应报告 gate 前后 score-blind 特征、几何类别、跟踪质量、候选可辨识性和 cluster 构成，但不能用评分来调门。

关门会保留更多场景，却把一个未在该区间验证过的回归输出包装成中心和分位边界。此时 NEX/NMD 只是“相对模型外推曲面的数值距离”，不是“相对人类参照的偏离”。它可以帮助检查方向是否依赖于门和样本选择，却不能承担人类不认可结论；即使数值有限、结果显著、置换通过、四格校正通过，也不修复参照本身在这些点没有校准依据的问题。

### 6. 预见的卡点与停止点

1. **WOD 特征/类别合同不闭合**：真实 score-stripped WOD 行出现未知类别、缺失特征或预处理不一致，立即停止，不准在看评分后改特征。
2. **支持重叠不足**：若主格三候选全通过的场景数低于功效门，停止确认性解释；不得自动把支持门关格升主。
3. **NEX 常数/并列过多**：若评分盲 bank 中有信息场景数不足，停止主检验；这属于端点信息不足，不是阴性科学结果。
4. **区间几何异常**：非有限边界、零/负半宽、极端窄宽导致归一化爆炸时，按冻结规则终态化；异常率超过预定阈值则整轮停止。
5. **candidate join 不唯一**：479 场景、每场景候选数、候选哈希、连接键或源顺序任一不满足冻结恒等式，评分连接前停止。
6. **跟踪/对手支持不足**：某个候选使用了不同历史或不同观测对手，或 tracker 质量与候选类别系统性相关，停止；否则 predictor 混入测量质量差异。
7. **抽样率与 recipe 不稳**：RQ010B 已显示 4 Hz 与 10 Hz 的候选 IPV 值相关仅约 `0.29–0.31`（`reports/knowledge/RQ010_wod_e2e_tracking_feasibility/decision.md:51-55`）。若冻结的低风险 rate sensitivity 使四格主次翻转，结论只能写成测量规格依赖。
8. **选择校正缺失**：若仍使用同一 479 场景而没有完整选择管线校准，停止在 post-selection sensitivity，不给“新验证”标签。
9. **低功效零结果**：每格实际场景数对应的最小可识别效应大于预先声明的科学最小效应，停止“无关联”措辞，只报“该样本只能排除更大的效应”。

### 7. 如何防止评分泄漏进上游

采用物理分阶段、最小权限、不可回写的三层隔离：

1. **G0/G1：纯 score-stripped 阶段。** 上游环境不挂载含评分的 TFRecord、CSV、pickle 或 joined table；RQ014 已查实原 TFRecord 内嵌评分，旧 reader 即使最后 drop 列也已经读过整行，所以“读后删除”不算盲（`reports/knowledge/RQ014_wod_e2e_rating_recovery/README.md:33-45`）。输入只允许哈希绑定的去评分 bundle。
2. **冻结收据。** 在任何评分访问前发布四格 manifest、envelope bytes、候选 bank、支持状态、attrition、主次顺序、功效门、停止规则、代码/环境哈希和全输出 schema；验收脚本扫描列名与序列化内容，确认没有 rating/preference/score 字段或派生代理。
3. **G2：一次受控连接。** 由与特征构建隔离的角色在内存中按候选哈希连接最少字段，只输出四格的聚合计数、效应、不确定性、置换统计与收据；不持久化逐条评分，不允许 partial leaderboard，不允许失败后改 recipe、支持门或阈值再连一次。
4. **泄漏负对照。** 在评分解锁前用伪标签只验证流程形状；正式运行检查 score 行置换后类型/分母不变，检查候选源顺序没有进入 predictor，并验证评分列从未参与缺失过滤、支持门、NEX/NMD 构造或有信息场景判定。

### 8. 独立功效推导

以场景为独立单位、双侧相关、80% power 作解析规划。Fisher-z 近似为

`|r|min = tanh((z_(1-alpha/2) + z_0.80) / sqrt(n-3))`。

若四格共同控制家族 `alpha=0.05`，Bonferroni 后每格 `alpha=0.0125`，分子约为 `2.498+0.842=3.340`。据此手算：

| 实际有信息场景 n | 四格家族下最小 `|r|`（约） | 仅一个预先主格、alpha=0.05 时最小 `|r|`（约） |
|---:|---:|---:|
| 42 | 0.489 | 0.421 |
| 75 | 0.375 | 0.319 |
| 98 | 0.330 | 0.280 |
| 120 | 0.300 | 0.253 |
| 174 | 0.250 | 0.211 |
| 275 | 0.200 | 0.168 |
| 476 | 0.152 | 0.128 |

反过来，在四格家族下，80% power 识别 `|r|=0.40/0.30/0.25/0.20` 约需 `n=66/120/174/275` 个有信息场景；若严格层级检验、只给唯一预先主格 `alpha=0.05`，约需 `n=47/85/124/194`。这些是解析近似；RWS 离散、并列多且可能只有少数场景簇，实际所需 n 只会更高，最终应以冻结的场景级置换功效为准。

四格不能共用一个名义 n：`NEX+门开` 通常因区间内 0、三候选常数和支持门而 n 最小；`NMD+门开` 会多一些；两个门关格可能接近结构上限，但解释等级最低。每格必须在评分盲 bank 冻结后，分别用自己的 `n_informative_scenes` 报最小效应。仅报告最小效应仍不够防止把零结果写成“无关联”；还必须事先声明科学上最小有意义效应，并把零结果写成“排除了大于该格最小可识别门槛的效应”或“功效不足，不能排除”。

## 第二阶段：与 `RQ020_kickoff_v3.md` 逐条对照

### 总体对照结论

任务书正确抓住了 RQ014 的主 NEX 未通过、唯一 NMD 候选是选择后结果、支持门必须进入设计、四格必须全报、场景才是独立单位、评分只能一次连接、类别词表和低功效必须显式检查。这些骨架与我的独立推导高度一致。

但任务书最核心的论证——“新 envelope + 不再搜索，所以本轮是前瞻检验，p 值只需校正四格”（任务书 `:54-65`）——不成立。它把 predictor 的一部分变新误当成把**选择样本**变新。`R04N / CH-W25 / H20` 是在同一批评分上由旧 envelope 的 320-cell 搜索选出的；本轮的四格和“NEX 是否复活”问题本身也由同一批结果启发。P4 又被任务书明确设计为“与 RQ014 最接近的复算”（`:147-161`）。因此历史选择链没有断开。

### 一致项

1. **RQ014 定性一致。** 任务书没有把 `r=-0.384, n=42` 当成预期效应，也承认 primary NEX 为零、fold/LOO/LOCO 不是独立复制（`:39-72`）。
2. **四格结构和主次方向一致。** P1 是 NEX+支持门开，P3 是 NMD+支持门开，P2/P4 是门关敏感性；P1 最贴近“超出纯人类参照范围”的构念（`:147-161`）。
3. **支持诊断一致。** 类别词表覆盖、三候选完整、场景数而不是候选行数、支持率及路径类型分层都应在评分连接前冻结（`:120-125, 141-175`）。
4. **防泄漏框架一致。** 上游评分盲、连接前预注册、只连接一次、连接后不改上游、不得输出逐场景值（`:178-220`）。
5. **低功效边界一致。** 每格需报告自己的场景数和最小可识别效应，小 n 的零结果不得写成“无关联”（`:204-209`）。
6. **窗口纪律一致。** 原生 4 Hz、CH-W25、H20、完整闭窗、无边界缩短、无跨窗导数复用，都是可审计的固定实现（`:96-115`）。

### 我的方案更强之处

1. **承认继承的选择效应。** 任务书只校正四格；我的方案要求新评分样本，或把同数据结果降为 post-selection sensitivity。若硬要同数据错误率标定，置换必须重演“旧 320 格选 recipe → 新 envelope 四格检验”的完整程序。
2. **不给门关格人类参照语义。** 任务书要求 P2/P4 与 P1/P3 一样给效应、区间和 Holm p，容易产生同等合法性的视觉效果。我的方案把 P2/P4 限定为外推敏感性，不让其进入“人类不认可”证据。
3. **把 WOD 适用性设为门，而不是有趣诊断。** 任务书称支持率高于 RQ009 M3 即“纯人-人重建改善迁移”（`:163-168`）；这个比较不成立，因为两版特征、距离维度、分格和阈值不同。更高通过率可能只是门更宽，不能单凭比例证明区间在 WOD 上校准得更好。
4. **功效口径与多重校正一致。** 任务书 `n=42→rho≈0.42`、`n=100→rho≈0.28`、`n=150→rho≈0.23` 是单一 `alpha=0.05` 的近似，却同时规定四格 Holm。按四格最保守的首个阈值 `alpha=0.0125`，相应值约为 `0.489/0.327/0.269`，明显更弱。
5. **有明确不升格规则。** P1 因支持或并列不足时，不能把 P3、P2 或 P4升为主；任务书虽要求全报和不剔除小 n 格，但没有明确禁止后续把显著次格承接主张。
6. **要求冻结 WOD→RQ016C 查询合同。** RQ016C 的合同只列 22 个数值、4 个类别输入，以及 row-level `mechanism2_gate_ok`（`feature_contract.json:20-60`；`HOWTO_score_external_rows.md:5-13,26-30`）。任务书没有定义这些列如何由每个 WOD `scene×candidate×tau` 生成，也没有定义 row 级门如何汇总为 anchor、候选和“三候选完整场景”的 P1/P3 纳入规则。

## 收尾问题

### Q1

**沿用整套赢家配置作新的确认性检验不正当；作复算或敏感性正当。** 要分开看各组件：`terminal estimator row` 是 RQ014 全部 cells 共用的固定实现，因此没有在 320 格内部新增选择倍数；但 R04N 是 2 个采样分支之一，CH-W25 是 8 个时窗之一，H20 是 2 个视界之一，最终组合与 NMD_MEAN/RWS 一起由同一评分数据上的赢家产生。复用组合会继承选择效应。

换纯人类 envelope 不能自动清零该效应，因为场景、候选、响应、上游轨迹和被选 recipe 没变，新旧 envelope 又共享大量运动学上下文。真正补救是用未参与 RQ014 的新评分样本检验。若只能用现有 479，最多做 post-selection sensitivity；完整旧选择流程加新四格的置换可标定全局零假设下的程序性假阳性率，但仍不能把同数据结果改造成前瞻复制。clean replay 和只校正四格都不是补救。

### Q2

**四格是正确的诊断家族，但不是四个同等有效的确认性终点。** 我的排序为：

1. `NEX + 支持门开`：唯一主格，直接对应超出纯人类参照范围。
2. `NMD + 支持门开`：关键次格，回答支持域内离中心越远是否越不受偏好。
3. `NEX + 支持门关`：外推敏感性，只检查结论是否依赖门。
4. `NMD + 支持门关`：最接近旧结果，但最容易把外推中心/半宽当成人类参照，解释力最低。

所以把 P1 定为主格在构念上正确，前提是先补齐支持门汇总合同、P1 的 n 达到预设功效门、并使用未参与选择的响应样本。更好的推断结构是 P1 单独主检验，P3 层级次检验，P2/P4 只作描述性敏感性；不应让两个门关格与门开格共享同等科学地位。

### Q3

**论证站不住。** “本轮不再搜索”只说明运行时没有新增自适应分支，不说明当前配置是 outcome-independent 的。R04N/CH-W25/H20 来自同一 479 场景的旧 320-cell 搜索；“换参照后 NEX 是否复活”也由旧 NEX/NMD 结果触发。四格 Holm 只处理本轮四个 p 的并列选择，漏掉了产生 recipe 和问题的历史选择。

p 值仍可作为“在把当前四格强行视为固定时”的描述性统计，但不能提供本轮所声称的前瞻型 I 类错误控制。要获得可解释的确认性 p，需使用新响应数据；要在同数据上标定程序性错误率，则每次置换必须重演旧 320 格选择及随后新参照检验，而任务书明确禁止这样做。

### Q4

**可以报告数值，但只能作为支持外外推敏感性；不能把它报告成人类参照偏离证据。** P2/P4 的有限 NEX/NMD 数值说明“固定模型在 pre-OOD-mask 曲面上给出了某个距离”，不说明该点的 M、L、U 具有校准过的人类分布含义。若与 P1/P3 同样展示正常置信区间、Holm p 和“越界”语言，确实是在给无效量套合法外观。

正当报告方式是单独放在 `unsupported extrapolation sensitivity` 表中，随行给支持失败分子/分母、距离分布和“不参与人类不认可判定”的固定声明；其显著性不能挽救 P1/P3 的失败，也不能进入主结论。

### Q5

**最可能的伪成立路径是：被 RQ014 选中的 recipe 在新旧 envelope 间保留相关结构，P3 或 P4 再次出现负相关。** RQ016C 与 RQ009 M3 共享大量运动学上下文；同一 R04N/CH-W25/H20 会保留原来那批容易形成三候选排序差异的场景。偶然负向对齐因此可能跨 envelope 延续。

它可以通过现有全部检查：数值健康正常；类别词表覆盖；三候选和哈希连接完整；P3 甚至可通过支持门；四格 Holm 显著；当前四格 max-stat permutation 显著；`shuffled_ipv` 失去信号；非线性 envelope 距离还可能比简单 kinematics baseline 表现更好。所有这些检查都从“recipe 已固定”之后开始，没有重演当初从 320 格选择该 recipe 的步骤。因此最终看起来像一次干净前瞻验证，实际仍可能只是旧选择在相关 predictor 下的延续。

### Q6

**缺少一个冻结的 `WOD scene×candidate×tau → RQ016C query row → scene inclusion` 合同。** 现有 `feature_contract.json` 只列 22+4 个输入列，HOWTO 只定义 row-level 输出；任务书没有定义每列如何从 WOD 轨迹构造、`target_ipv_future` 与每个 tau 的 IPV 如何对齐、anchor 级支持失败如何汇总到候选和场景、以及 `_MEAN` 在部分 anchor 失败时是否仍计算。

没有这个合同，`stage2_envelope.json` 中的“支持通过率”“四格场景数”和 NEX/NMD_MEAN 都没有唯一分母或唯一语义，属于无法解释，不是仅仅不够美观。另一个直接执行 blocker 是任务书当前只给了含评分的 `frames.tfrecord` 路径，未给 score-stripped 输入的精确 manifest/hash 绑定。

### Q7

设四格各自评分盲冻结后的有信息场景数为 `n1,n2,n3,n4`。按场景独立、双侧、80% power，并用四格家族最保守的 Holm 首阈值 `alpha=0.05/4=0.0125`，每格规划近似为：

- P1：`MDE1 = tanh(3.340/sqrt(n1-3))`；只有支持门语义闭合时可解释。
- P2：`MDE2 = tanh(3.340/sqrt(n2-3))`；只是外推数值关联的 MDE。
- P3：`MDE3 = tanh(3.340/sqrt(n3-3))`；支持域内中心距离关联。
- P4：`MDE4 = tanh(3.340/sqrt(n4-3))`；只是外推数值关联的 MDE。

具体数值：`n=42/100/150/476` 时，四格家族下约只能识别 `|r|=0.489/0.327/0.269/0.152`。要识别 `|r|=0.40/0.30/0.25/0.20`，约需 `n=66/120/174/275`。若按我建议把 P1 设为唯一 `alpha=0.05` 主检验，相应所需 n 约为 `47/85/124/194`。这些仍是乐观解析近似；RWS 离散、NEX 并列与场景簇会进一步降低实际功效。

任务书只要求“每格报 MDE”**不够**。还必须在连接前冻结最小科学相关效应 `delta*`，用置信区间或等效性检验回答是否能排除 `|r|>=delta*`。非显著且区间仍覆盖有意义效应时，只能写“不确定/功效不足”；MDE 表不能把它升级为“无关联”。任务书给的 `n=42→0.42` 等数字又没有与其四格 Holm 口径对齐，必须订正。

### Q8

**总判定：`NO_GO`。** 这是针对任务书声称的“前瞻的人类不认可验证”，不是否定评分盲阶段的支持率与数据健康诊断价值。

**单一最重要修改：把正式偏好检验移到未参与 RQ014 选择的全新评分样本上。** 在现有 479 场景上只冻结 recipe、envelope、四格、支持合同与功效门；用新的 WOD 候选或对预先冻结候选的新一轮独立人类评分作最终响应。若拿不到新评分，现有 479 的阶段三只能降级为 post-selection sensitivity，不能承担社会判断阶梯第三级的确认性主张。

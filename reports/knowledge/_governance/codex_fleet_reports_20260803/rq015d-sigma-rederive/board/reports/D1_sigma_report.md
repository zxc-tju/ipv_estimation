# D1 sigma report

## 1. 一句话结论

**不需要重定全局 sigma。** 公式核验确认当前权重使用 `w ∝ exp(-mse/(2*sigma^2))` 且 sigma=0.1 对应系数 50；当前主要张力不是“全局硬 argmax”，而是同一个全局尺度在低 MSE 间距行上给出近均匀、在高 MSE 间距行上给出硬 argmax。把 sigma 改到 `sigma_rederived=0.234741` 会让权重更平，降低硬 argmax 但进一步增加近均匀，不是单一修复。

**且计划 §5 预设的方向被数据否掉了。** `median(sqrt(min_mse)) = 0.2347` 比现行 0.1 **大 2.3 倍**，
即重定规则会让权重**更平**；而 §5 担心的是"σ 太小 ⇒ 过锐 ⇒ 虚假自信"。**数据指向反方向。**
分源更极端：nuplan `0.0941` vs waymo `1.1153`，**跨 11.9 倍**——
单是这一条就足以否掉"存在一个全局 σ"的前提。

## 1b. 第三类失效：400 行（17.4%）对任何 σ 免疫 —— 本轮最重要的发现

**7 个候选的 MSE 逐位相同 ⇒ 在这些锚点上，改变 IPV 候选完全不改变预测轨迹。**

| 事实 | 数值 |
|---|---|
| 行数 | **400 / 2,300 = 17.39%** |
| 在 nuplan 内占比 | **400 / 1,150 = 34.78%**（**waymo 为 0 行**） |
| 占 "约 59% 失效地板" 的比重 | **29.2%** |
| σ 敏感性 | σ = 0.01 → 1.0 全程 `k_eff` 恒为 **7.000**（**完全免疫**） |
| `ipv_log` 取值 | **唯一值 `0.0`**（对称候选网格上的均匀加权平均）= pathological constant |
| `at_grid_boundary` | 全等 ⇒ argmin 返回下标 0 ⇒ **虚假触发** |
| 行内 vs 行间 | 行内 7 候选相同，行间 MSE 不同（0.0310 / 0.0021 / 0.00051）⇒ **不是求解器输出恒定** |

**这是一个独立于已知两类的第三类失效。** 它既不是数值下溢（那是 log 域改写能救的），
也不完全是"当前网格与模型下平坦"（那是"分不太开"）——这批是
**IPV 在前向模型里对这些锚点根本没有作用**。
因此 **σ 重定与 log 域改写对它都无效，全量重跑也救不回来。**

它 100% 集中在 nuplan（waymo 0 行），与 B 轨独立观察到的
"nuplan D2 63.56% / D1 仅 1.06%" 异常画像**结构一致**——两条 track 独立收敛到同一结构。

**附带的数据质量缺陷（需下游注意）**：由于全等 tie 使 argmin 恒返回下标 0，
**1,185 个 `at_grid_boundary` 标记里有 400 个（33.8%）是假阳性**；
真正的非退化边界行只有 785 行（其 `ipv_log` 有 330 个不同取值，形态正常）。
**若有下游逻辑消费这个标记，它正在吃三分之一的噪声。**

可辩护表述：这 400 行的权重近均匀不是 σ 过大造成的，改 σ 也无法改变；
**其 IPV 数值不携带候选间的判别信息。**

## 8. Step 5 判定与理由链

B3 判定：**不需要重定全局 sigma**。

理由链：第一，权重公式反推精确确认 sigma=0.1 的系数 50，没有隐藏的 `n_obs` 乘法或公式偏移。第二，原始 legacy 的高近均匀占比中有 603 行是下溢兜底导致的精确均匀，不是 sigma 性质；修正这一路径属于 B2 数值实现问题。第三，扣掉兜底行后，近均匀主要对应真实候选 MSE 间距小于 `2*sigma^2=0.02` 的情形，表示候选间判别信息不足。第四，waymo 的硬 argmax 确实存在，但提高全局 sigma 只会把全局和 nuplan 推向更平，不能同时解决两端。下游应保留 sigma=0.1，并把 `k_eff/q_eff` 作为逐行判别信息诊断；近均匀行不应被解释为候选间有明确区分。

第五，存在一类 σ 与 log 域改写**都无法触及**的失效（§1b 的 400 行 / 17.4%），
它把"是否重定 σ"这个问题的可改善上限进一步压低。

## Q2：是否存在单一 σ 同时缓解两端？——**监督方选项 2 成立：不存在**

**两条曲线在整个扫描区间内严格反向单调**，没有共同低谷：
`near%` 随 σ 单调**上升**（ALL 25.00→81.96），`hard%` 随 σ 单调**下降**（ALL 35.57→0.17）。
调 σ 只是在两端之间**搬运误差**，不消除误差：

- 从 σ=0.1 走到 σ=0.02，合计失效仅从 66.04% 降到 59.48%（**6.6 个百分点**），
  代价是硬 argmax 从 12.87% **翻倍到 29.43%**；
- 合计失效在**任何** σ 下都不低于约 **59%**（ALL 全程 59.48%–82.13%）——存在一个地板，σ 打不穿；
- 名义最优 σ=0.02 是一个**内部极小值**（两侧邻点 σ=0.01 为 60.57%、σ=0.03 为 60.61%），
  但**极浅**——6.56 pp 的改善换来硬 argmax 翻倍以上（+16.56 pp），不是好交易；
  且三个源的曲线形态互相冲突：
  nuplan 在**任何** σ 下都是近均匀主导（σ=0.01 时仍有 45.22% 近均匀），
  waymo 在小 σ 下是硬 argmax 主导（σ=0.01 时 50.09%）。
  合并最优对 nuplan 意味着把硬 argmax 从 1.91% 抬到 14.52%，**对该源是净损失**。

**结论**：σ 调参解决不了这个问题。真正的修法是 log 域改写（已证不可归零）＋弃权闸，
而不是重定 σ。**保持 σ = 0.1 不动。**

其中一部分地板是**结构性不可动**的：本报告 Leader 自查附录 §B 的 400 行
（样本 17.4%）7 个候选 MSE 逐位相同，`k_eff` 在 σ=0.01→1.0 全程恒为 7.000，
**对任何 σ 免疫**。
